# BiliScript 宣传片方向

## 范围与叙事

1920×1080、30fps、35 秒，共 1050 帧，中文横版产品宣传片。范围是浏览器扩展的 B 站视频字幕阅读、AI 概览、AI 对话、无字幕视频的语音转写、多字幕轨视频的双语对照、字幕复制与导出、联网搜索辅助核对、四主题阅读界面与 AI 平台接入；不扩展到其他产品平台。真实录屏与扩展 UI 保持功能含义和操作顺序，所有场景、字幕与 `audio.cues` 共用这条时间轴。

叙事只有一条线：**用户场景第一，一眼看懂扩展能帮我干啥**。每个镜头都是“左边一句话说清这个功能解决什么，右边真实文摘面板证明它做得到”，课程内容只作被阅读的对象，不作主标题。全片承诺一句话：**长视频不用从头看到尾——搜得到原话、读得懂结构、问得清依据。**

本文只记录创作方向与镜头意图。镜头帧区间以 `timeline.mjs` 和 `outro-timeline.mjs` 为准，声音事件以 `audio.mjs` 为准，字幕区间以 `captions.mjs` 为准；制作命令与产物位置见 `README.md`。

## 空间景深无框融合方向：全片晨读亮场空间（Morning Light Spatial）+ 跨次元三幕原声问答接龙 + 纸感翻页隐喻

采用 **无框空间景深融合（`fusion-light`）方案**：

- **全片晨读亮场基底（`#FBFBFD → #F4F5F8`）**：保持清爽通透的晨读亮场空间底色与细腻漫反射光晕，去除机械外框线、顶角方框标签与解释性说明副标，依靠 **Z 轴空间透视（`perspective(1600px)`、`rotateX`、`rotateY`）**、**多层漫反射阴影（`ELEVATION`）** 与 **毛玻璃悬浮层（`backdrop-filter: blur`）** 建立前后景深主次。
- **跨次元三幕原声问答接龙**：保持 120 BPM 原创合成器纯音乐《BiliScript Pulse》与动作音效，围绕原片《大模型公开课》赵斌老师的真实讲课原声建立“找现象 → 抓成因 → 问破局”三幕式问答接龙；原声分别落在搜词跳播、章节金句与追问举证三镜，配乐执行 `11.5 dB` 平滑闪避，底部由原片字幕承接。
- **「读视频」书页立体翻折与纸感隐喻**：开场点击播放器右侧悬浮按钮后，文摘面板以左边缘为书脊执行 `rotateY` 书页翻开，叠加书脊折痕阴影与细微纸张纤维肌理（`PaperGrainOverlay`）；金句卡继续沿用纸感肌理与暖调台灯 `ReadingLampBeam`。
- **四主题阅读界面连续切换**：去掉后台设置菜单，直接让同一个阅读面板连续切换 `蓝雾玻璃 · 日间` → `蓝雾玻璃 · 夜间` → `数字刊物 · 日间` → `数字刊物 · 夜间` 4 种主题的实际阅读效果，字号从 `100%` 递进到 `118%`，数字刊物使用衬线杂志排版。

### 镜头锚点

- **开场一键总结**：首帧就是 B 站播放页全屏、不模糊，鼠标从右侧进入；左栏第一行 *“点一下播放器，”* 浮出，右侧中部浮现轨道图标与环形高亮时补第二行 *“整期视频自动读完。”*，点击脉冲后文摘面板以书页翻开，小字 *“TL;DR · 分节要点 · 时间戳”* 出现；随后真实 AI 对话里答案开始逐段流出，镜头先平移到面板、再推近开头 TL;DR，最后稳留。首帧不再有痛点卡，也不再有品牌横幅；品牌名只在片尾出现。
- **搜词跳播**：顶部标题带 *“记得 UP 主提过那句话？搜词秒跳那一秒。”*；“幻觉”做一次横向切片错位与聚合，连续缩进真实搜索框，机械键盘敲击与回车后跳到 `04:07`，切入赵老师原声“……也很难避免幻觉。”，底部原片字幕承接。
- **章节金句**：左侧主标题强调 **3 秒提炼章节脉络与金句**，下方是当前 B 站视频参照窗；右侧聚焦卡局部放大两章（时间戳胶囊 + 一句摘要）与底部金句栏，点击“生成金句卡”后抬升单张 3D 拍立得，切入赵老师 `02:32` 原声“如果他不答，一定是零分！”印证。
- **追问举证**：左侧 *“带着问题追问视频，点按时间戳让 UP 主亲自举证。”*；右侧面板只留一句提问与两条单行结论，`04:44–05:15` 时间戳胶囊放大发光；点击后参照窗跳到 `04:44`，播放器推近，底部出现赵老师原声大号字幕“这里有一个研究……”，再回到结论收束。
- **转写 / 双语**：同一镜头拆成两条完整主张，各占一拍。第一拍左栏 *“没字幕的视频，整段转成文字。”* + *“免费语音识别 · 412 条字幕”*，面板停在真实单轨态（轨道名“自配平台转写（英文）”、状态行“语音识别完成，已生成 412 条字幕。”、只有英文主行、“双语字幕”开关关闭并注明“本视频只有一条字幕轨”）；第二拍同帧切到 *“中英双轨，逐句对照着看。”* + *“选中复制 · SRT / Markdown / TXT”*，面板同时换到双轨态（“英文”+“双语”徽标、中文副行、开关打开、参照窗“中英双轨”），随后指针点“复制字幕”，状态行变为“字幕已复制到剪贴板。”。不再有第三个独立标题。
- **联网核对**：左侧 *“UP 主说得对不对？AI 联网检索辅助核对。”*，副标点明 *“超纲概念听不懂？检索公开网页和论文摘要，附来源链接，方便进一步核实。”*；右侧面板展示用户追问，点亮“联网搜索”后检索 arXiv:2405.04434 等来源，给出论文摘要中的比较条件与超纲概念补充。
- **四主题**：左侧标题 *“蓝雾玻璃或纸质刊物，四款主题日夜皆宜。”*，副标说明同一面板连续切换四套日夜主题；右侧同一阅读面板按拍切换四种主题、字号放大与衬线排版，左侧主题列表同步高亮当前档位。
- **AI 平台**：不做开发者配置说明，中心铭牌用用户受益视角 *“接入你顺手的 AI 大脑”*，副标 *“支持切换 DeepSeek、Kimi、Qwen 等 14+ 平台，亦支持本地模型”*；透视椭圆轨道承载 14 家官方 Logo 依次点亮，每个 Logo 配一声阶递进的立体声冒泡。
- **片尾**：品牌落定后口号 *“在 B 站，读下一条视频。”* 浮现，兼容行同拍出现（22px，带 Chrome / Edge 标识）：*“Chrome / Edge 等 Chromium 浏览器 · 免费开源”*；双按钮（Edge 应用商店 / GitHub 开源）随后落位，指针点击时迸发 B 站粉金“三连星火”；定格段换成三能力回收 *“搜原话 · 读章节 · 问依据”*，音乐署名留在底部。

## 混音与响度指标

- **配乐与动态**：120 BPM Tech Pop 原创合成（《BiliScript Pulse》，MIT License），按段落塑造动态包络：开场克制 → 章节阅读清透、金句与对话推进 → 转写 / 四主题 / AI 平台递进高潮 → 品牌落定 → 片尾母带淡出。
- **真实讲课人声与闪避**：三幕原声分别在搜词（`04:07`）、章节金句（`02:32`）、追问举证（`04:44`）切入，配乐执行 `11.5 dB` 持续平滑闪避并抽稀中频打击乐与琶音；镜头切点与品牌落定叠加 `60–90Hz` 短促 Sub-hit，动作音效触发点执行 `2.5–6 dB` 预闪避。
- **成片音频硬指标**：综合响度 `-14.0 ± 0.5 LUFS`，动态范围 `LRA 4.0–6.0`，True Peak `≤ -1.0 dBTP`，无削波。
