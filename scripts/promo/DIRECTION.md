# BiliScript 宣传片方向

## 范围与叙事

1920×1080、30fps、35 秒，共 1050 帧，中文横版产品宣传片。范围是浏览器扩展的 B 站视频字幕阅读、AI 概览、AI 对话、无字幕语音转写/双语对照/字幕导出、联网搜索辅助核对、四主题阅读界面与 AI 平台接入；不扩展到其他产品平台。真实录屏与扩展 UI 保持功能含义和操作顺序，所有场景、字幕与 `audio.cues` 共用这条时间轴。

叙事只有一条线：**用户场景第一，一眼看懂扩展能帮我干啥**。每个镜头都是“左边一句话说清这个功能解决什么，右边真实文摘面板证明它做得到”，课程内容只作被阅读的对象，不作主标题。

本文只记录创作方向与镜头意图。镜头帧区间以 `timeline.mjs` 和 `outro-timeline.mjs` 为准，声音事件以 `audio.mjs` 为准，字幕区间以 `captions.mjs` 为准；制作命令与产物位置见 `README.md`。

## 空间景深无框融合方向：全片晨读亮场空间（Morning Light Spatial）+ 跨次元三幕原声问答接龙 + 纸感翻页隐喻

采用 **无框空间景深融合（`fusion-light`）方案**：

- **全片晨读亮场基底（0–35s，`#FBFBFD → #F4F5F8`）**：全片保持清爽通透的晨读亮场空间底色与细腻漫反射光晕（`rgba(251, 114, 153, 0.055)` 与 `rgba(0, 174, 236, 0.045)`），彻底去除机械外框线、顶角方框标签与解释性说明副标，依靠 **Z 轴空间透视（`perspective(1600px)`、`rotateX`、`rotateY`）**、**多层漫反射阴影（`ELEVATION`）** 与 **毛玻璃悬浮层（`backdrop-filter: blur`）** 建立前后景深主次。
- **跨次元三幕原声问答接龙（`04:07` / `02:32` / `04:44` 跳播与点题锚点）**：保持 120 BPM 原创合成器纯音乐《BiliScript Pulse》与动作音效，围绕原片《大模型公开课》赵斌老师的真实讲课原声建立“找现象 → 抓成因 → 问破局”三幕式问答接龙——`5.60s` 在字幕镜头跳播 `04:07` 后切入 *“……也很难避免幻觉。”*；`7.50–10.30s` 概览章节阶段保持配乐清透供观众阅读 2 个局部放大章节卡片，`10.30s` 指针点击金句区弹出单张拍立得金句卡并在 `10.37s` 切入 `02:32` 原声印证 *“如果他不答，一定是零分！”*；`16.80s` 在追问镜头推近原片时切入 *“这里有一个研究……”*。配乐同步执行 `11.5 dB` 平滑闪避并避让中高频配器，三幕原声均由画面底部原片字幕承接，让产品能力演变为与原片老师的跨次元对话。
- **「读视频」书页立体翻折与夜读台灯纸感隐喻**：片头点击播放页下方“文摘”入口后，右侧 **文摘面板** 以左边缘为书脊执行 `rotateY(-54deg → 0deg)` 立体书页翻开展平，叠加书脊折痕阴影与细微纸张纤维肌理（`PaperGrainOverlay`），中央横幅亮出主张 *“BiliScript · 在 B 站直接「读」视频”*；金句卡片叠加纸感肌理、三维翻页微倾与温暖定向夜读台灯光束（`ReadingLampBeam`）。
- **四主题阅读界面连续切换（25.00–28.00s）**：去掉后台设置菜单，直接让同一个阅读面板连续切换 `蓝雾玻璃 · 日间` → `蓝雾玻璃 · 夜间` → `数字刊物 · 日间（暖羊皮纸）` → `数字刊物 · 夜间（暖炭黑）` 4 种主题的实际阅读效果，搭配字号动态放大（`100% → 106% → 112% → 118%`）与数字刊物衬线杂志排版过渡。

### 关键手法与镜头锚点

- **开场单句痛点稳留 + 拉远点开文摘面板（0.00–3.50s）**：`0.00–1.70s`（`frames 0..51`）全屏居中只留一张无框毛玻璃痛点卡 *“1 小时干货长视频，还在收藏夹吃灰？”*，第 0 帧即完整可读、100% 不透明，核心词「还在收藏夹吃灰？」以大字重与荧光笔扫光高亮，`0.13s`（`frame 4`）触发一次双段气泡弹出音（`pop.wav`），随后整句稳留到 `1.70s` 供观众读完；`1.70–1.90s`（`frames 51..57`）痛点卡向纵深坍缩退场，B 站公开课页面从 `1.28x` 拉远归位、模糊 `5.5px → 1.2px`，晨读薄纱透明度 `0.88 → 0.24`；`1.87s`（`frame 56`）指针点击播放页下方“文摘”入口并泛起粉色脉冲，右侧 **文摘面板** 在 `1.87–2.40s` 沿书脊折痕展开；`1.90s`（`frame 57`）起中央横幅 *“BiliScript · 在 B 站直接「读」视频”* 大字浮现，`2.53s`（`frame 76`）响指声（`finger-snap.wav`）配合横幅轻弹与镜头 `1.0x → 1.08x` 向右侧面板推进，停留至镜头结束。
- **第一幕问答·搜索词切片与机械键盘回车（3.50–4.37s）**：顶部标题带 *“记得 UP 主提过那句话？搜词秒跳那一秒。”*；“幻觉”只做一次横向切片错位与聚合，随后同一个词连续缩进真实搜索框，配合双键清脆机械轴敲击声与 `4.17s` 回车键平衡杆触发反馈（`mech-key-1/2` + `mech-enter`）。
- **磁吸吸附瞬移与 `04:07` 原声回应（5.50–7.50s）**：以实际选中的字幕条目和真实时刻文本 `04:07` 为匹配剪辑锚点，在 `5.53s`（`frame 166`）触发磁吸吸附音效（`snap.wav`）与画面高光瞬移缩放；`5.57s` 起画面底部居中出现大号原片字幕 `04:07 · 赵老师原声 · “……也很难避免幻觉。”`，`5.60s` 切入赵老师真实讲课原声（`1.60s`），播放器随人声泛起柔和粉色环境光晕。
- **第二幕问答·局部放大双章节脉络与金句拍立得印证（7.50–13.00s）**：左侧 66px 功能主标题 *“48 分钟长视频，3 秒提炼章节脉络与金句。”*，下方为当前 B 站视频参照窗（*正在阅读：复旦赵斌《大模型公开课》48:16*）。`7.50–10.30s`（`frames 0..83`）右侧以蓝雾玻璃聚焦卡局部放大展示 2 个代表性章节（`00:00` 评分机制与语言本质、`02:32` 商业价值与数据局限，各带时间戳胶囊与一句精简摘要）及底部金句提炼栏，期间不播讲课原声，让观众无干扰读清提炼内容；`9.90s`（镜头内 `frame 72`）指针点击底部「生成金句卡」按钮泛起脉冲，`10.30s`（镜头内 `frame 84`）背景聚焦卡柔化退后，从金句栏抬升单张 3D 拍立得金句成片（*“他只要去答这个题目，得的就不是零分；但如果他不答，一定是零分！”*），叠加纸张肌理（`PaperGrainOverlay`）与暖调台灯光束（`ReadingLampBeam`）；`10.37s`（全局 `frame 311`）同步切入赵老师 `02:32` 原声印证 *“如果他不答，一定是零分！”*（`1.50s`）并在左下参照窗亮出底部原片字幕，`10.77s` 拍立得快门声（`polaroid-shutter.wav`）落定，`11.70s` 叠加原声淡出过渡音（`voice-fade.wav`），稳留至 `13.00s`。
- **面板失焦接续（12.80s / 18.80s / 22.30s / 24.80s）**：分别接续金句→AI 对话、AI 对话→无字幕转写与导出、无字幕转写与导出→联网搜索、联网搜索→四主题阅读。旧主体失焦退场 6 帧，干净切点，新主体合焦 7 帧。
- **第三幕问答·AI 对话时间戳跳播与 `04:44` 原声举证（13.00–19.00s）**：左侧 62px 功能主标题 *“带着问题追问视频，点按时间戳让 UP 主亲自举证。”*，以荧光笔高亮「追问视频」「时间戳」，下方为当前 B 站视频参照窗；右侧文摘面板只留一句提问（*“为什么作者说 AI 并非越强越好，适配才是关键？”*）与两条单行结论，`(04:44–05:15)` 时间戳胶囊放大发光；`15.80s`（全局 `frame 474`）指针点击胶囊，参照窗向 `04:44` 跳播；`16.80–18.13s` 播放器平滑推近放大、面板退到右上角，画面底部居中出现赵老师原声大号字幕 `04:44 · “这里有一个研究……”`，同步切入真实讲课原声（`1.33s`）；`18.13–19.00s` 回到结论要点收束。
- **痛点功能一·无字幕免费语音转写 / 双语对照 / 一键复制 Markdown 与导出 SRT（19.00–22.50s）**：左侧大字标题先呈现 *“遇到没字幕的视频？免费语音转写 · 双语对照。”*，后半段切换为 *“一键复制 Markdown，或导出 SRT · TXT 字幕。”*（严格基于真实字幕复制/导出功能，不虚构导出笔记）；右侧真实文摘面板依次演示無字幕视频触发免费语音转写逐行生成字幕、开启中英双语对照译文层、以及指针点击顶部工具栏「复制 Markdown」弹出 `已复制带时间戳 Markdown · 支持导出 SRT / TXT` 浮层。
- **痛点功能二·AI 联网检索与超纲补充（22.50–25.00s）**：左侧大字主标题 *“UP 主说得对不对？AI 联网检索辅助核对。”*，底部副标点明 *“超纲概念听不懂？检索公开网页和论文摘要，附来源链接，方便进一步核实”*；右侧文摘面板展示用户追问 *“UP 主说 MLA 能省 93% KV Cache，有依据吗？这个超纲概念怎么理解？”*，点亮「联网搜索」开关后检索 arXiv:2405.04434 等外部来源，并展示论文摘要中的比较条件与超纲概念通俗补充。
- **四主题阅读切换·如读纸质刊物（25.00–28.00s）**：去掉后台设置菜单，左侧极简标题由 *“日夜双模，蓝雾清透。”* 平滑翻转为 *“如读纸质刊物，排版随心。”*；右侧同一个文摘阅读面板以每拍约 `0.75s` 连续切换 `蓝雾玻璃 · 日间` → `蓝雾玻璃 · 夜间` → `数字刊物 · 日间（暖羊皮纸）` → `数字刊物 · 夜间（暖炭黑）` 4 种主题的实际阅读效果，字号由 `100%` 动态放大至 `118%`，数字刊物主题切换为杂志感衬线排版与章节首字下沉。
- **用户受益视角·接入你顺手的 AI 大脑（28.00–31.00s）**：去除“预设 / 自定义端点”等开发者配置术语，顶部与中心铭牌采用用户受益视角文案：**“接入你顺手的 AI 大脑 / 支持切换 DeepSeek、Kimi、Qwen 等 14+ 平台，亦支持本地模型”**（明确体现自由接入外部 API 与本地模型，不使用“内置”表述）；透视椭圆轨道承载 14 家官方 Logo 与标准上屏名称依次点亮并叠加 14 个成音阶递进的立体声冒泡音效（`bubble-01..14.wav`）。
- **品牌落定与 B 站三连星火收束（31.00–35.00s）**：去除与前文重复的纯文字快闪卡，在 `31.27s` 直接展开 BiliScript 品牌图标与品牌名，`31.60s` 浮现口号 *“在 B 站，读下一条视频。”*、`31.73s` 出现无框毛玻璃 Edge / GitHub 安装入口及下方高级灰辅文（`支持 Chrome / Edge 等 Chromium 内核浏览器 · 免费开源`）；`32.93s` 指针点击“Edge 应用商店”时迸发 B 站粉金双色几何“三连星火”粒子脉冲（`TripleLikeBurst`），`33.50s` 起进入最终定格到片尾。

## 混音与响度指标

- **配乐与动态**：120 BPM Tech Pop 原创合成（《BiliScript Pulse》，MIT License），按段落塑造动态包络（开场单句痛点克制 → 概览章节阅读清透、金句与对话稳健推进 → 痛点功能/四主题阅读/AI 平台递进高潮 → 品牌落定与标语落点 → `33.0–35.0s` 母带淡出）。
- **跨次元三幕真实讲课人声切入与闪避**：`5.60s`（`04:07` 原声回应，*“……也很难避免幻觉。”*）、`10.37s`（`02:32` 原声印证金句，*“如果他不答，一定是零分！”*）与 `16.80s`（`04:44` 原声举证，*“这里有一个研究……”*）切入原片真实讲课原声，配乐执行 `11.5 dB` 持续平滑闪避并抽稀中频打击乐与琶音；镜头切点与品牌落定叠加 `60–90Hz` 短促 Sub-hit，动作音效触发点执行 `2.5–6 dB` 预闪避。
- **成片音频硬指标**：综合响度 `-14.0 ± 0.5 LUFS`，动态范围 `LRA 4.0–6.0`，True Peak `≤ -1.0 dBTP`，无削波。
