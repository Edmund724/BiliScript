# BiliScript 宣传片方向

## 范围与叙事

1920×1080、30fps、33 秒，共 990 帧，中文横版产品宣传片。范围是浏览器扩展的 B 站视频字幕阅读、AI 概览、AI 对话、外观设置与 AI 平台预设；不扩展到其他产品平台。真实录屏保持功能含义和操作顺序，20–25 秒为 AI 平台预设镜头，25–33 秒为能力、品牌与安装收束。所有场景、字幕与 `audio.cues` 共用这条时间轴。

## 混合动效方向：前半程连续工作台（A）+ 后半程全屏切色与加速蒙太奇（B）

采用 **`huashu-motion` 混合方案**：
- **前半程（0–17s，方向 A：纸面连续工作台 + 抽层联动）**：以 `#FBFAFC` 纸白阅读色为基底，顶部建立统一的 `EditorialHeaderBand`（`x: 0..1180, y: 0..156`，左对齐 `104px` 安全线，对比度 `12.6:1`），保证片头与字幕搜索标题完全落定于干净纸面背景，不压在原片讲者面部或板书细节上；核心交互物（`04:07` 时间戳匹配胶囊、金句分享卡、AI 对话 `(04:44–05:15)` 时间戳点击与同屏原片跳播验证）从面板抽层抬升，形成完整交互闭环。
- **后半程（17–33s，方向 B：全屏切色硬切 + 满幅出血特写 + 加速蒙太奇 + 急停收尾）**：17.0s 进入外观切换时打破缩略框限制，在 17.70s（`frame 531`）与 18.90s（`frame 567`）伴随 Toggle / Pop 音效触发斜切多边形整屏背景换肤（纸白 `#FBFAFC` → 深邃夜读 `#10151C` → 暖棕精读 `#1A1412`），中央以双栏巨幅出血画框（占画面 `>72%` 面积）对比播放器与面板；20.0s 进入 `≥55%` 屏宽的满幅出血“添加 AI 平台”预设弹窗；20.73s 左侧亮出 `168px` 的 `14` 计数并停留 `0.73s`，随后同一元素连续平移缩放至顶部居中，引导 14 家官方 Logo 以 `4.5` 帧错峰（总跨度 `2.22s`）铺满画面中央（占高 `44.8%`）；25.0s 四张内嵌微缩 UI 预览的能力卡按拍亮起，28.67s 配乐急停留白 `0.38s` 后在 29.20s 敲响品牌落定和弦。

### 关键手法与镜头锚点

- **首帧完成态海报（0.00–0.16s）**：第 0–4 帧即呈现 `100%` 不透明度的完成态封面（B 站播放器 + 已展开的 BiliScript 文摘面板 + 顶部 `EditorialHeaderBand` 内的品牌标记与 `在 B 站，读视频` 标题），与独立导出的 `BiliScript-promo-cover.png` 共享同一视觉语言；第 5 帧（`0.17s`）起无缝衔接到指针移向“文摘”入口并点击展开的实拍序列。
- **搜索词切片（3.00–3.43s）**：“幻觉”只做一次横向切片错位与聚合；错位 2–3 帧、归位 6–8 帧，随后同一个词连续缩进真实搜索框。
- **时间戳接续（5.00–6.00s）**：以实际选中的字幕条目和真实时刻文本 `4:07` 为匹配剪辑锚点，伴随 `TimestampMatchCallout` 高亮；点击后沿同一位置、尺寸和运动方向进入播放器，再拉回显示真实跳播结果与底部 `已跳播至 04:07` 验证条。
- **金句卡抬升与完整取景（7.00–11.00s）**：章节概览与金句分享卡均使用完整包含圆角、顶栏与底栏的面板裁切（`CHAPTER_CROP` / `SHARE_CROP`），不出现半截边缘；左侧同步显示章节胶囊与实时色板切换胶囊（`紫粉·橙金` → `灰蓝·深棕` → `雾蓝·深海`）。
- **面板失焦（10.80–11.23s 与 16.80–17.23s）**：分别接续金句→AI 对话、AI 对话→外观设置。旧主体失焦退场 6 帧，干净切点，新主体合焦 7 帧。
- **AI 对话时间戳同屏跳播验证（11.00–17.00s）**：右侧对话主体卡与底部输入卡均使用完整不裁边的 `880px` 宽裁切（正文达 `22.8px ≥ 22px`）；13.80s（全局 `frame 414`）指针移动并点击回答中的 `(04:44–05:15)` 蓝色时间戳并触发点击音效与波纹；14.80–15.80s 同屏展示左侧已跳播至 `04:44` 的原片播放器（含顶部蓝底跳播提示与底部对应字幕条）与右侧总结面板，15.80–17.00s 回到总结要点收束。
- **全幅主题切色与双栏大画幅（17.00–20.00s）**：顶部标题栏单行收纳标题与实时主题状态胶囊，下方 `y: 164..1080` 以左播放器（`680px`）+ 右深色/阅读色板面板（`1010px`，正文 `≥22px`）满幅出血呈现；17.70s 与 18.90s 斜切扫屏切换全屏主题底色。
- **平台预设满幅出血与单一连续 `14` 计数（20.00–25.00s）**：20.00–21.73s 右侧以 `1080px` 宽（占屏宽 `56.25% ≥ 55%`）满幅出血展示“添加 AI 平台”预设弹窗（文字 `28px+`，无任何 API Key 或敏感字段）；20.73s（`countAt = 22`）左侧亮出 `168px` 的 `14 个 AI 平台预设` 并静止停留 `22` 帧（`0.73s ≥ 0.65s`），随后在 `frames 44..58` 由同一组件连续平移缩放至顶部居中，不发生旧元素消失与新元素重现；14 家官方 Logo 卡（`224×226`）自 `wallAt = 52` 起以 `cardStagger = 4.5` 帧错峰入场，总揭示时长 `2.22s`（落在 `2.0–2.8s` 区间），两行网格高 `484px`（占屏高 `44.8%`，底部留白 `<30%`），并在 `collapseAt = 136` 向画面中心径向汇聚，于 `24.93s` 完全清场。
- **能力卡微缩预览与音乐急停（25.00–33.00s）**：四张 `400×360` 能力大卡（双语字幕 / 字幕导出 / 语音识别 / 联网搜索）内嵌代码构建的微缩 UI 视觉预览，分别在 `25.50 / 26.00 / 26.50 / 27.00s` 按拍亮起并伴随逐级递增的音效与和弦；`28.67s` 四卡向中心汇聚同时配乐急停留白，`29.20s` 图标清晰落定并触发 Resolve 和弦，随后展开品牌名、口号与 Edge / GitHub 安装入口。

## 混音与响度指标

- **配乐与动态**：120 BPM Tech Pop 原创合成（《BiliScript Pulse》，MIT License），按段落塑造动态包络（片头克制 → 概览/对话稳健推进 → 外观/平台/四拍能力递进高潮 → 28.67s 急停呼吸 → 29.20s 品牌落定 → 31–33s 淡出）。
- **切点低频瞬态与闪避**：7 个核心切点（`3.0 / 7.0 / 11.0 / 17.0 / 20.0 / 25.0 / 29.0s`）叠加 `60–90Hz` 短促 Sub-hit；所有动作音效触发点对背景乐执行 `2.5–6 dB` 预闪避（Ducking），确保点击、键盘、切换与和弦清晰浮出。
- **成片音频硬指标**：综合响度 `-14.0 ± 0.5 LUFS`，动态范围 `LRA 4.0–6.0`，True Peak `≤ -1.0 dBTP`，无削波。
