# BiliScript 宣传片方向

## 范围与叙事

1920×1080、30fps、35 秒，共 1050 帧，中文横版产品宣传片。范围是浏览器扩展的 B 站视频字幕阅读、AI 概览、AI 对话、无字幕视频的语音转写、多字幕轨视频的双语对照、字幕复制与导出、联网搜索辅助核对、四主题阅读界面与 AI 平台接入；不扩展到其他产品平台。真实录屏与扩展 UI 保持功能含义和操作顺序，所有场景、字幕与 `audio.cues` 共用这条时间轴。

叙事只有一条线：**用户场景第一，一眼看懂扩展能帮我干啥**。每个镜头都是“左边一句话说清这个功能解决什么，右边真实文摘面板证明它做得到”，课程内容只作被阅读的对象，不作主标题。全片承诺一句话：**长视频不用从头看到尾——搜得到原话、读得懂结构、问得清依据。**

本文只记录创作方向与镜头意图。镜头帧区间以 `timeline.mjs` 和 `outro-timeline.mjs` 为准，声音事件以 `audio.mjs` 为准，字幕区间以 `captions.mjs` 为准；制作命令与产物位置见 `README.md`。

## 空间景深无框融合方向：全片晨读亮场空间（Morning Light Spatial）+ 跨次元三幕原声问答接龙 + 真实面板与分享卡质感

采用 **无框空间景深融合（`fusion-light`）方案**：

- **全片晨读亮场基底（`#FBFBFD → #F4F5F8`）**：保持清爽通透的晨读亮场空间底色与细腻漫反射光晕，不设机械外框线、顶角方框标签与解释性说明副标，依靠 **Z 轴空间透视（`perspective(1600px)`、`rotateX`、`rotateY`）**、**多层漫反射阴影（`ELEVATION`）** 与 **毛玻璃悬浮层（`backdrop-filter: blur`）** 建立前后景深主次。
- **跨次元三幕原声问答接龙**：保持 120 BPM 原创合成器纯音乐《BiliScript Pulse》与动作音效，围绕原片《大模型公开课》赵斌老师的真实讲课原声建立“找现象 → 抓成因 → 问破局”三幕式问答接龙；原声分别落在搜词跳播、章节金句与追问举证三镜，配乐执行 `11.5 dB` 平滑闪避，底部由原片字幕承接。
- **真实面板滑出与金句分享卡隐喻**：开场点击播放器右侧悬浮按钮后，文摘面板按真实扩展 CSS 曲线从右向左滑出并带左缘微回弹，直接呈现已发送总结提示词与短暂思考过渡；概览金句分享卡沿用真实 `mist-deep-sea` 渐变色团、`rays` 几何细线纹样与物理噪点肌理（`PaperGrainOverlay`）。
- **四主题阅读界面连续切换**：不展示后台设置菜单，直接让同一个阅读面板连续切换 `蓝雾玻璃 · 日间` → `蓝雾玻璃 · 夜间` → `数字刊物 · 日间` → `数字刊物 · 夜间` 4 种主题的实际阅读效果，字号从 `100%` 递进到 `118%`，数字刊物使用衬线杂志排版。

### 镜头锚点

- **开场痛点到解药**：首帧是 B 站播放页全屏、不模糊，播放器右下角亮起 *48:16* 时长徽标，左栏先抛痛点 *“48 分钟硬核长视频，没时间从头看？”*；鼠标从右侧进入，点击悬浮按钮后痛点淡出，换成 *“点一下，3 秒变成结构化文章。”* 与小字 *“TL;DR · 分节要点 · 时间戳”*。文摘面板从右向左滑出后直接逐段流出 TL;DR 与主题要点，不展示提示词与思考过程；镜头随后平移到面板、推近 TL;DR 并稳留。品牌名只在片尾出现。
- **配乐与动态**：120 BPM Tech Pop 原创合成（《BiliScript Pulse》，MIT License），按段落塑造动态包络：开场克制 → 章节阅读清透、金句与对话推进 → 转写 / 四主题 / AI 平台递进高潮 → 品牌落定 → 片尾母带淡出。
- **真实讲课人声与闪避**：三幕原声分别在搜词（`04:07`）、章节金句（`02:32`）、追问举证（`04:44`）切入，配乐执行 `11.5 dB` 持续平滑闪避并抽稀中频打击乐与琶音；镜头切点与品牌落定叠加 `60–90Hz` 短促 Sub-hit，动作音效触发点执行 `2.5–6 dB` 预闪避。
- **成片音频硬指标**：综合响度 `-14.0 ± 0.5 LUFS`，动态范围 `LRA 4.0–6.0`，True Peak `≤ -1.0 dBTP`，无削波。
