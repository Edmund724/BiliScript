# BiliScript 宣传片方向

## 范围与叙事

1920×1080、30fps、33 秒，共 990 帧，中文横版产品宣传片。范围是浏览器扩展的 B 站视频字幕阅读、AI 概览、AI 对话、外观设置与 AI 平台预设；不扩展到其他产品平台。真实录屏保持功能含义和操作顺序，20–25 秒为 AI 平台预设镜头，25–33 秒为能力、品牌与安装收束。所有场景、字幕与 `audio.cues` 共用这条时间轴。

## 空间景深无框融合方向：全片晨读亮场空间（Morning Light Spatial）+ 真实原片讲课人声跳播验证

采用 **无框空间景深融合（`fusion-light`）方案**：
- **全片晨读亮场基底（0–33s，`#FBFBFD → #F4F5F8`）**：全片保持清爽通透的晨读亮场空间底色与细腻漫反射光晕（`rgba(251, 114, 153, 0.055)` 与 `rgba(0, 174, 236, 0.045)`），彻底去除机械外框线（`1px/2px/3px solid`）、顶角方框标签与解释性说明副标，依靠 **Z 轴空间透视（`perspective(1600px)`、`rotateX`、`rotateY`）**、**多层漫反射阴影（`ELEVATION`）** 与 **毛玻璃悬浮层（`backdrop-filter: blur`）** 建立前后景深主次。
- **真实原片讲课人声切入（`04:07` 与 `04:44` 跳播锚点）**：保持 120 BPM 原创合成器纯音乐《BiliScript Pulse》与动作音效，在 `5.10s`（`SubtitleScene` 点击 `04:07` 跳播）与 `14.80s`（`ChatScene` 点击 `(04:44–05:15)` 跳播）切入原片《大模型导论》赵斌老师的真实讲课原声（*“也很难避免幻觉”* / *“这里有一个研究”*），配乐同步执行 `8.5 dB` 平滑闪避，画面下方同步浮现无框毛玻璃声波条（`VoiceWaveBar`），让跳播功能从视觉走向视听双重闭环。
- **晨读亮场内的深色夜读与色板预览（17–20s）**：不做整屏纯黑切色，始终保持晨读亮场空间底色；右侧悬浮大画幅真实外观设置面板，左侧在三维透视空间中悬浮展示深色夜读磨砂板岩界面（`#0B0D13`）与暖棕数字刊物色板预览卡，顶部配无框毛玻璃色板胶囊（`晨读纸白` / `深色夜读` / `数字刊物`）。

### 关键手法与镜头锚点

- **首帧完成态空间海报（0.00–0.16s）**：第 0–4 帧呈现 `100%` 不透明度的无框空间完成态封面（左侧无框大字标题 `把长视频，读成一页好文章。` + Z 轴抬升的 `02:32` 核心论点毛玻璃卡 + 右侧三维微倾的真实 BiliScript 概览面板），与独立导出的 `BiliScript-promo-cover.png` 共享同一视觉语言；第 5 帧（`0.17s`）起衔接到指针移向“文摘”入口并点击展开的实拍序列，右侧展开面板带深邃左侧空间投影。
- **搜索词切片（3.00–3.43s）**：“幻觉”只做一次横向切片错位与聚合；错位 2–3 帧、归位 6–8 帧，随后同一个词连续缩进真实搜索框。
- **时间戳接续与真实原声切入（5.00–7.00s）**：以实际选中的字幕条目和真实时刻文本 `4:07` 为匹配剪辑锚点，伴随无框毛玻璃 `TimestampMatchCallout` 抬升；`5.10s`（`frame 153`）切入原片真实讲课人声 *“也很难避免幻觉”*（`1.60s`），播放器随人声泛起柔和粉色环境光晕，底部浮现动态声波验证条 `04:07 · “也很难避免幻觉”`。
- **Z 轴三层章节抽层与金句抬升（7.00–11.00s）**：7.00–8.73s 左侧采用 `fusion-light` 三层 Z 轴空间叠放——`00:00` 与 `04:27` 章节行后退柔化（`opacity: 0.48, blur(0.6px)`），`02:32` 核心论点卡向前抬升并带柔光投影，右侧真实概览面板作三维透视微倾；8.73–11.00s 真实金句抬升为前景无框分享卡，远景悬浮原片播放器与声波条，左侧同步展示无框毛玻璃色板胶囊（`紫粉·橙金` → `灰蓝·深棕` → `雾蓝·深海`）。
- **面板失焦（10.80–11.23s 与 16.80–17.23s）**：分别接续金句→AI 对话、AI 对话→外观设置。旧主体失焦退场 6 帧，干净切点，新主体合焦 7 帧。
- **AI 对话时间戳同屏跳播与人声验证（11.00–17.00s）**：右侧无框悬浮对话主体卡与底部输入卡展示追问与带时间戳回答，左侧悬浮 `04:44 – 05:15` 章节上下文卡；13.80s（全局 `frame 414`）指针移动并点击回答中的 `(04:44–05:15)` 蓝色时间戳；14.80–15.80s 同屏展示左侧已跳播至 `04:44` 的原片播放器与右侧总结面板，同步切入原片真实讲课人声 *“这里有一个研究”*（`1.35s`）与声波条 `04:44 · “这里有一个研究”`，15.80–17.00s 回到总结要点收束。
- **亮场空间内的深色夜读与色板预览（17.00–20.00s）**：保持晨读亮场背景，顶部右侧悬浮 `晨读纸白` / `深色夜读` / `数字刊物` 状态胶囊；右侧以无框大画幅（`1010px` 宽）展示真实外观与色板切换面板，左侧在三维透视空间中同步将悬浮预览面切换为深色夜读磨砂界面与暖棕刊物界面。
- **平台预设满幅出血与单一连续 `14` 计数（20.00–25.00s）**：20.00–21.73s 右侧以 `1080px` 宽（占屏宽 `56.25% ≥ 55%`）无框空间悬浮展示“添加 AI 平台”预设弹窗（无任何 API Key 或敏感字段）；20.73s（`countAt = 22`）左侧亮出 `168px` 的 `14 个 AI 平台预设` 并静止停留 `22` 帧（`0.73s ≥ 0.65s`），随后在 `frames 44..58` 由同一组件连续平移缩放至顶部居中；14 家官方 Logo 无框毛玻璃卡（`224×226`）自 `wallAt = 52` 起以 `cardStagger = 4.5` 帧错峰入场，总揭示时长 `2.22s`，并在 `collapseAt = 136` 向画面中心径向汇聚，于 `24.93s` 完全清场。
- **无框能力卡微缩预览与音乐急停（25.00–33.00s）**：四张 `400×360` 无框毛玻璃能力大卡（双语字幕 / 字幕导出 / 语音识别 / 联网搜索）内嵌微缩 UI 视觉预览，分别在 `25.50 / 26.00 / 26.50 / 27.00s` 按拍抬升亮起并伴随逐级递增的音效与和弦；`28.67s` 四卡向中心汇聚同时配乐急停留白，`29.20s` 图标清晰落定并触发 Resolve 和弦，随后展开品牌名、口号与无框毛玻璃 Edge / GitHub 安装入口。

## 混音与响度指标

- **配乐与动态**：120 BPM Tech Pop 原创合成（《BiliScript Pulse》，MIT License），按段落塑造动态包络（片头克制 → 概览/对话稳健推进 → 外观/平台/四拍能力递进高潮 → 28.67s 急停呼吸 → 29.20s 品牌落定 → 31–33s 淡出）。
- **真实讲课人声切入与闪避**：`5.10s`（`04:07` 跳播，*“也很难避免幻觉”*）与 `14.80s`（`04:44` 跳播，*“这里有一个研究”*）切入原片真实讲课原声，配乐执行 `8.5 dB` 持续平滑闪避；其余 7 个核心切点叠加 `60–90Hz` 短促 Sub-hit，动作音效触发点执行 `2.5–6 dB` 预闪避。
- **成片音频硬指标**：综合响度 `-14.0 ± 0.5 LUFS`，动态范围 `LRA 4.0–6.0`，True Peak `≤ -1.0 dBTP`，无削波。
