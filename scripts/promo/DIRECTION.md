# BiliScript 宣传片方向

## 范围与叙事

1920×1080、30fps、35 秒，共 1050 帧，中文横版产品宣传片。范围是浏览器扩展的 B 站视频字幕阅读、AI 概览、AI 对话、外观设置与 AI 平台预设；不扩展到其他产品平台。真实录屏保持功能含义和操作顺序，20.5–25.5 秒为 AI 平台预设镜头，25.5–35.0 秒为能力、首尾呼应闪回闭环、品牌与安装收束。所有场景、字幕与 `audio.cues` 共用这条时间轴。

本文只记录创作方向与镜头意图。镜头帧区间以 `timeline.mjs` 和 `outro-timeline.mjs` 为准，声音事件以 `audio.mjs` 为准，字幕区间以 `captions.mjs` 为准；制作命令与产物位置见 `README.md`。

## 空间景深无框融合方向：全片晨读亮场空间（Morning Light Spatial）+ 跨次元三幕原声问答接龙 + 纸感翻页隐喻

采用 **无框空间景深融合（`fusion-light`）方案**：
- **全片晨读亮场基底（0–33s，`#FBFBFD → #F4F5F8`）**：全片保持清爽通透的晨读亮场空间底色与细腻漫反射光晕（`rgba(251, 114, 153, 0.055)` 与 `rgba(0, 174, 236, 0.045)`），彻底去除机械外框线（`1px/2px/3px solid`）、顶角方框标签与解释性说明副标，依靠 **Z 轴空间透视（`perspective(1600px)`、`rotateX`、`rotateY`）**、**多层漫反射阴影（`ELEVATION`）** 与 **毛玻璃悬浮层（`backdrop-filter: blur`）** 建立前后景深主次。
- **跨次元三幕原声问答接龙（`04:07` / `02:32` / `04:44` 跳播与点题锚点）**：保持 120 BPM 原创合成器纯音乐《BiliScript Pulse》与动作音效，围绕原片《大模型导论》赵斌老师的真实讲课原声建立“找现象 → 抓成因 → 问破局”三幕式问答接龙——在 `5.10s`（`SubtitleScene` 提问 *“记得老师提过「幻觉」，在哪一秒？”* 并点击 `04:07` 跳播）切入原声 *“……也很难避免幻觉。”*；在 `7.17s`（`OverviewScene` 提问 *“48 分钟公开课，AI 为什么爱犯幻觉？”* 呈现 `02:32` 核心论点卡）切入原声 *“如果他不答，一定是零分！”* 并衔接到 `8.73s` 包含该句原话的金句分享卡；在 `14.80s`（`ChatScene` 提问 *“为什么作者说 AI 并非越强越好，适配才是关键？”* 并点击 `(04:44–05:15)` 跳播）切入原声 *“这里有一个研究……”*。配乐同步执行 `11.5 dB` 平滑闪避并避让中高频配器，三幕原声均由画面底部居中的大号原片字幕承接，让产品能力演变为与原片老师的跨次元对话。
- **「读视频」书页立体翻折与夜读台灯纸感隐喻**：片头（`0.00–1.40s`）做减法聚焦，去除四周弹幕、进度条与顶角标识，只保留前景三张痛点三连问大卡并将核心词（「收藏夹吃灰」「死活拖不到」「追问没人答」）做字重放大与荧光笔高亮；点击播放页下方“文摘”入口后，右侧 **文摘面板** 以左边缘为书脊执行 `rotateY(-34deg → 0deg)` 立体书页翻开展平，叠加书脊折痕阴影与细微纸张纤维肌理（`PaperGrainOverlay`），顶部横幅亮出主张：*“不用等课代表，在 B 站直接「读」视频。”*；金句卡片与外观切换均叠加纸感肌理、三维翻页微倾与温暖定向夜读台灯光束（`ReadingLampBeam`）。
- **明暗模式 × 外观色板空间预览与打破第四面墙环境光伴随（17–20s）**：严格区分 `GLOSSARY.md` 定义的 **明暗模式**（`light` 浅色 | `dark` 深色）与 **外观色板**（`flyme` 蓝雾玻璃 | `editorial` 数字刊物）两条正交轴，顶部悬浮 `浅色 · 蓝雾玻璃` / `深色 · 夜读` / `数字刊物 · 暖纸衬线` 状态胶囊；当指针点击「深色 · 夜读」时，整个宣传片 1920×1080 大背景同步暗下并在卡片背后亮起温暖的琥珀色台灯光晕；切换到「数字刊物 · 暖纸衬线」时，全屏背景浮现出细腻的微黄纸张肌理感（`PaperGrainOverlay`），实现全局光影联动。

### 关键手法与镜头锚点

- **黄金前 3.5 秒聚焦三连问荧光高亮 + 主 Slogan 停留延长与向右侧插件栏推进（Zoom-in）（0.00–3.50s）**：0.00–1.40s（`frames 0..42`）以轻度柔化的 B 站公开课页面（`scale(1.34 → 1.30)`、`blur(4.5px)`）叠透光晨读薄纱为纯净景深底，三张无框毛玻璃痛点问题卡分别在 `0.00s`（`frame 0`）、`0.43s`（`frame 13`）、`0.87s`（`frame 26`）同屏错峰弹簧入场并触发双段气泡弹出音（`pop.wav` Pop-Pop），对核心痛点词（「收藏夹吃灰」「死活拖不到」「追问没人答」）施加大字重与动态荧光笔扫光高亮；`1.20–1.43s`（`frames 36..43`）三张问题卡向纵深坍缩退场，镜头急速拉远合焦；`1.40s`（`frame 42`）指针点击播放页下方“文摘”入口按钮并泛起粉色脉冲，右侧 **文摘面板** 在 `1.40–1.87s`（`frames 42..56`）沿书脊折痕以 `rotateY(-54deg → 0deg)` 书页翻折展开，同时核心主张 `BiliScript · 不用等课代表，在 B 站直接「读」视频。` 在画面中央偏左大字浮现并延长停留至 `2.40s`（`frames 40..72`），随后在 `2.40–3.27s`（`frames 72..98`，配合 `2.50s` `frame 75` 节拍切场响指声 `finger-snap.wav`）顺滑归位至左上角并同步执行镜头向右侧插件栏推进（`Zoom-in 1.0x → 1.34x`）聚焦右侧 `BiliScript` 文摘面板，全场景时长延长 0.5s（1 拍 @ 120 BPM）使后续全部场景保持严格踩拍。
- **第一幕问答·搜索词切片与机械键盘回车（3.50–4.37s）**：顶部标题带抛出问题 *“记得老师提过「幻觉」，在哪一秒？”*；“幻觉”只做一次横向切片错位与聚合，错位 2–3 帧、归位 6–8 帧，随后同一个词连续缩进真实搜索框，配合双键清脆机械轴敲击声与 `4.17s` 回车键平衡杆触发反馈（`mech-key-1/2` + `mech-enter`）。
- **磁吸吸附瞬移与 `04:07` 原声回应（5.50–7.50s）**：以实际选中的字幕条目和真实时刻文本 `4:07` 为匹配剪辑锚点，在 `5.53s`（`frame 166`）触发磁吸吸附音效（`snap.wav`）与画面高光瞬移缩放，伴随无框毛玻璃 `TimestampMatchCallout` 抬升；`5.60s`（`frame 168`）切入赵老师真实讲课原声回应 *“……也很难避免幻觉。”*（`1.60s`），播放器随人声泛起柔和粉色环境光晕，顶部浮现动态声波验证条 `04:07 · 赵老师原声回应 · “……也很难避免幻觉。”`。
- **第二幕问答·Z 轴章节抽层原声点题与金句拍立得实体交互（7.50–11.50s）**：7.50–9.23s 左侧标题提问 *“48 分钟公开课，AI 为什么爱犯幻觉？”*，下方采用三层 Z 轴空间叠放——`00:00` 与 `04:27` 章节行后退柔化，`02:32` 核心论点卡向前抬升并叠加纸纤维纹理；`7.67s`（`frame 230`）切入赵老师真实讲课原声点题 *“如果他不答，一定是零分！”*（`1.45s`），并在 `9.00s`（`frame 270`）叠加温润空气感原声淡出过渡音（`voice-fade.wav`），紧接着在 `9.23s`（`frame 277`）将包含这句原话的真实字幕段抬升为前景无框分享金句卡（*“他只要去答这个题目，得的就不是零分，但是他如果不答一定是零分……”*），叠加纸张肌理（`PaperGrainOverlay`）与暖调台灯光束（`ReadingLampBeam`）；在 `9.70s / 9.93s / 10.33s` 每次切换配色时触发成音阶递进的水滴快门声（`shutter-1..3.wav`）与三维翻页微倾；`10.63s`（`frame 319`）指针点击「保存 PNG」按钮，触发拍立得快门声（`polaroid-shutter.wav`）、快门微闪与右侧金句卡 3D 视差拍立得相纸弹起动效。
- **面板失焦（11.30–11.73s 与 17.30–17.73s）**：分别接续金句→AI 对话、AI 对话→外观设置。旧主体失焦退场 6 帧，干净切点，新主体合焦 7 帧。
- **第三幕问答·AI 对话时间戳跳播与 `04:44` 原声举证（11.50–17.50s）**：左侧 62px 功能主标题 *“带着问题追问视频，点按时间戳让 UP 主亲自举证。”*，以荧光笔高亮「追问视频」「时间戳」，下方为当前 B 站视频参照窗（*正在阅读：复旦赵斌《大模型公开课》48:16*）；右侧文摘面板只留一句提问（*“为什么作者说 AI 并非越强越好，适配才是关键？”*）与两条单行结论，`(04:44–05:15)` 时间戳胶囊放大发光；`14.30s`（全局 `frame 429`）指针点击胶囊，参照窗向 `04:44` 跳播；`15.30–16.63s` 播放器平滑推近放大、面板退到右上角，画面底部居中出现赵老师原声大号字幕 `04:44 · “这里有一个研究……”`，同步切入真实讲课原声（`1.35s`）；`16.63–17.50s` 回到结论要点收束。
- **明暗模式 × 外观色板空间预览与全局环境光伴随（17.50–20.50s）**：顶部右侧悬浮 `浅色 · 蓝雾玻璃` / `深色 · 夜读` / `数字刊物 · 暖纸衬线` 状态胶囊；右侧展示真实外观设置面板，左侧悬浮预览面伴随三维翻页微倾依次切换：`18.20s`（`frame 546`）指针点击「深色 · 夜读」时全片大背景同步暗下并在卡片背后亮起温暖的琥珀色台灯光晕；`19.40s`（`frame 582`）指针切换到「数字刊物 · 暖纸衬线」时全片大背景浮现细腻微黄纸张肌理感。
- **平台预设微距实证、中心铭牌与 14 家官方 Logo 透视椭圆环绕（20.50–25.50s）**：20.50–21.70s 右侧以 `976px` 无框空间悬浮展示“添加 AI 平台”弹窗里已展开的平台预设下拉菜单（真机录屏自源片第 `106` 帧起截取，跳过含 API 地址与 API Key 输入框的表单画面），左侧只留两行标题 *“选择平台，从预设开始。”*；`21.70s`（`shotsExitAt = 36`）弹窗右移淡出，`21.97s`（`plateAt = 44`）画面中心浮起大号核心铭牌 `14 个 AI 平台预设`（副标仅 `另支持自定义端点`）；`22.23s`（`orbitAt = 52`）透视椭圆轨道淡入，14 家官方 Logo 与标准上屏名称先以低透明度占满整条轨道，再沿同一椭圆依次点亮，间隔 `logoStagger = 3.75` 帧（120 BPM 十六分音符），并叠加 14 个成音阶递进的立体声冒泡音效（`bubble-01..14.wav`）；`23.86s` 全部点亮后轨道以每帧 `0.42°` 缓慢空间自转，近端卡牌放大、远端缩小并降低不透明度；`25.03s`（`exitAt = 136`）阵列淡出，于 `25.43s` 完全清场。轨道只承载 Logo 与上屏名称，不叠分类胶囊、利益点长文或任何配置字段。

## 混音与响度指标

- **配乐与动态**：120 BPM Tech Pop 原创合成（《BiliScript Pulse》，MIT License），按段落塑造动态包络（片头克制 → 概览/对话稳健推进 → 外观/平台/四拍能力递进高潮 → 28.67s 急停呼吸 → 29.20s 品牌落定 → 31–33s 淡出）。
- **跨次元三幕真实讲课人声切入与闪避**：`5.10s`（`04:07` 原声回应，*“……也很难避免幻觉。”*）、`7.17s`（`02:32` 原声点题，*“如果他不答，一定是零分！”*）与 `14.80s`（`04:44` 原声举证，*“这里有一个研究……”*）切入原片真实讲课原声，配乐执行 `11.5 dB` 持续平滑闪避并抽稀中频打击乐与琶音；8 个核心转折与切点（含 `1.80s` 镜头拉远切入点）叠加 `60–90Hz` 短促 Sub-hit，动作音效触发点执行 `2.5–6 dB` 预闪避。
- **成片音频硬指标**：综合响度 `-14.0 ± 0.5 LUFS`，动态范围 `LRA 4.0–6.0`，True Peak `≤ -1.0 dBTP`，无削波。
