# BiliScript 宣传片方向

## 范围与叙事

1920×1080、30fps、35 秒，共 1050 帧，中文横版产品宣传片。范围是浏览器扩展的 B 站视频字幕阅读、AI 概览、AI 对话、外观设置与 AI 平台预设；不扩展到其他产品平台。真实录屏保持功能含义和操作顺序，20.5–25.5 秒为 AI 平台预设镜头，25.5–35.0 秒为四拍能力快切、品牌与安装收束。所有场景、字幕与 `audio.cues` 共用这条时间轴。

叙事只有一条线：**用户场景第一，一眼看懂扩展能帮我干啥**。每个镜头都是“左边一句话说清这个功能解决什么，右边真实文摘面板证明它做得到”，课程内容只作被阅读的对象，不作主标题。

本文只记录创作方向与镜头意图。镜头帧区间以 `timeline.mjs` 和 `outro-timeline.mjs` 为准，声音事件以 `audio.mjs` 为准，字幕区间以 `captions.mjs` 为准；制作命令与产物位置见 `README.md`。

## 空间景深无框融合方向：全片晨读亮场空间（Morning Light Spatial）+ 跨次元三幕原声问答接龙 + 纸感翻页隐喻

采用 **无框空间景深融合（`fusion-light`）方案**：

- **全片晨读亮场基底（0–35s，`#FBFBFD → #F4F5F8`）**：全片保持清爽通透的晨读亮场空间底色与细腻漫反射光晕（`rgba(251, 114, 153, 0.055)` 与 `rgba(0, 174, 236, 0.045)`），彻底去除机械外框线、顶角方框标签与解释性说明副标，依靠 **Z 轴空间透视（`perspective(1600px)`、`rotateX`、`rotateY`）**、**多层漫反射阴影（`ELEVATION`）** 与 **毛玻璃悬浮层（`backdrop-filter: blur`）** 建立前后景深主次。
- **跨次元三幕原声问答接龙（`04:07` / `02:32` / `04:44` 跳播与点题锚点）**：保持 120 BPM 原创合成器纯音乐《BiliScript Pulse》与动作音效，围绕原片《大模型导论》赵斌老师的真实讲课原声建立“找现象 → 抓成因 → 问破局”三幕式问答接龙——`5.60s` 在字幕镜头跳播 `04:07` 后切入 *“……也很难避免幻觉。”*；`7.67s` 在概览章节脉络推进时切入 `02:32` 论点 *“如果他不答，一定是零分！”*，并在 `10.10s` 把这句话抬成单张金句拍立得；`15.30s` 在追问镜头推近原片时切入 *“这里有一个研究……”*。配乐同步执行 `11.5 dB` 平滑闪避并避让中高频配器，三幕原声均由画面底部居中的大号原片字幕承接，让产品能力演变为与原片老师的跨次元对话。
- **「读视频」书页立体翻折与夜读台灯纸感隐喻**：片头点击播放页下方“文摘”入口后，右侧 **文摘面板** 以左边缘为书脊执行 `rotateY(-54deg → 0deg)` 立体书页翻开展平，叠加书脊折痕阴影与细微纸张纤维肌理（`PaperGrainOverlay`），中央横幅亮出主张 *“BiliScript · 在 B 站直接「读」视频”*；金句卡片叠加纸感肌理、三维翻页微倾与温暖定向夜读台灯光束（`ReadingLampBeam`）。
- **明暗模式 × 外观色板三连切（17.50–20.50s）**：严格区分 `GLOSSARY.md` 定义的 **明暗模式**（`light` 浅色 | `dark` 深色）与 **外观色板**（`flyme` 蓝雾玻璃 | `editorial` 数字刊物）两条正交轴。外层 1920×1080 舞台全程保持晨光暖白亮场，不铺黑底、不换纸底；单屏只留左上极简大字标题与居中偏右的一块真实文摘面板，面板随切换音效依次呈现 `浅色 · 蓝雾玻璃` → `深色 · 夜读模式` → `数字刊物 · 暖炭黑赤陶衬线`，琥珀色台灯光晕与暖调阴影只落在面板及其外沿。

### 关键手法与镜头锚点

- **开场单句痛点稳留 + 拉远点开文摘面板（0.00–3.50s）**：`0.00–1.70s`（`frames 0..51`）全屏居中只留一张无框毛玻璃痛点卡 *“1 小时干货长视频，还在收藏夹吃灰？”*，第 0 帧即完整可读、100% 不透明，核心词「还在收藏夹吃灰？」以大字重与荧光笔扫光高亮，`0.13s`（`frame 4`）触发一次双段气泡弹出音（`pop.wav`），随后整句稳留到 `1.70s` 供观众读完；`1.70–1.90s`（`frames 51..57`）痛点卡向纵深坍缩退场，B 站公开课页面从 `1.28x` 拉远归位、模糊 `5.5px → 1.2px`，晨读薄纱透明度 `0.88 → 0.24`；`1.87s`（`frame 56`）指针点击播放页下方“文摘”入口并泛起粉色脉冲，右侧 **文摘面板** 在 `1.87–2.40s` 沿书脊折痕展开；`1.90s`（`frame 57`）起中央横幅 *“BiliScript · 在 B 站直接「读」视频”* 大字浮现，`2.53s`（`frame 76`）响指声（`finger-snap.wav`）配合横幅轻弹与镜头 `1.0x → 1.08x` 向右侧面板推进，停留至镜头结束。
- **第一幕问答·搜索词切片与机械键盘回车（3.50–4.37s）**：顶部标题带 *“记得 UP 主提过那句话？搜词秒跳那一秒。”*；“幻觉”只做一次横向切片错位与聚合，随后同一个词连续缩进真实搜索框，配合双键清脆机械轴敲击声与 `4.17s` 回车键平衡杆触发反馈（`mech-key-1/2` + `mech-enter`）。
- **磁吸吸附瞬移与 `04:07` 原声回应（5.50–7.50s）**：以实际选中的字幕条目和真实时刻文本 `04:07` 为匹配剪辑锚点，在 `5.53s`（`frame 166`）触发磁吸吸附音效（`snap.wav`）与画面高光瞬移缩放；`5.57s` 起画面底部居中出现大号原片字幕 `04:07 · 赵老师原声 · “……也很难避免幻觉。”`，`5.60s` 切入赵老师真实讲课原声（`1.60s`），播放器随人声泛起柔和粉色环境光晕。
- **第二幕问答·章节脉络 2.6 秒主角化与金句单卡定格（7.50–11.50s）**：左侧 66px 功能主标题 *“48 分钟长视频，3 秒提炼章节脉络与金句。”*，下方为当前 B 站视频参照窗（*正在阅读：复旦赵斌《大模型公开课》48:16*）与 `02:32` 底部原片字幕。`7.50–10.10s`（`frames 0..77`）整段留给右侧真实概览面板的章节脉络时间轴，不做二次遮挡；`7.67s`（全局 `frame 230`）切入赵老师原声点题 *“如果他不答，一定是零分！”*（`1.45s`），`9.00s` 叠加温润空气感原声淡出过渡音（`voice-fade.wav`）；`10.10s`（`frames 78..119`）直接抬升一张金句拍立得成片（*“他只要去答这个题目，得的就不是零分；但如果他不答，一定是零分！”*），带纸张肌理（`PaperGrainOverlay`）、暖调台灯光束（`ReadingLampBeam`）与 3D 翻页微倾，`10.57s` 拍立得快门声（`polaroid-shutter.wav`）落定时定格，停留到镜头结束。
- **面板失焦（11.30–11.73s 与 17.30–17.73s）**：分别接续金句→AI 对话、AI 对话→外观设置。旧主体失焦退场 6 帧，干净切点，新主体合焦 7 帧。
- **第三幕问答·AI 对话时间戳跳播与 `04:44` 原声举证（11.50–17.50s）**：左侧 62px 功能主标题 *“带着问题追问视频，点按时间戳让 UP 主亲自举证。”*，以荧光笔高亮「追问视频」「时间戳」，下方为当前 B 站视频参照窗；右侧文摘面板只留一句提问（*“为什么作者说 AI 并非越强越好，适配才是关键？”*）与两条单行结论，`(04:44–05:15)` 时间戳胶囊放大发光；`14.30s`（全局 `frame 429`）指针点击胶囊，参照窗向 `04:44` 跳播；`15.30–16.63s` 播放器平滑推近放大、面板退到右上角，画面底部居中出现赵老师原声大号字幕 `04:44 · “这里有一个研究……”`，同步切入真实讲课原声（`1.35s`）；`16.63–17.50s` 回到结论要点收束。
- **明暗模式 × 外观色板三连切（17.50–20.50s）**：左侧 `76px` 极简标题先讲明暗模式（*“明暗模式切换，夜读台灯护眼。”*），`19.40s` 起改讲外观色板（*“外观色板定制，如读纸质刊物。”*）；右侧真实外观设置面板保留录屏切镜：`18.20s`（`frame 546`）切深色夜读，面板自身转深、外沿亮起琥珀色台灯光晕；`19.40s`（`frame 582`）切数字刊物，面板转暖炭黑底 `#171513`、深暖褐卡 `#211E1B` 与暖赤陶 `#E07A5F` 点缀，标题与正文换衬线字型；全屏底色不随模式变化。
- **平台预设微距实证、中心铭牌与 14 家官方 Logo 透视椭圆环绕（20.50–25.50s）**：20.50–21.70s 右侧以 `976px` 无框空间悬浮展示“添加 AI 平台”弹窗里已展开的平台预设下拉菜单（真机录屏自源片第 `106` 帧起截取，跳过含 API 地址与 API Key 输入框的表单画面），左侧只留两行标题 *“选择平台，从预设开始。”*；`21.70s`（`shotsExitAt = 36`）弹窗右移淡出，`21.97s`（`plateAt = 44`）画面中心浮起大号核心铭牌 `14 个 AI 平台预设`（副标仅 `另支持自定义端点`）；`22.23s`（`orbitAt = 52`）透视椭圆轨道淡入，14 家官方 Logo 与标准上屏名称先以低透明度占满整条轨道，再沿同一椭圆依次点亮，间隔 `logoStagger = 3.75` 帧（120 BPM 十六分音符），并叠加 14 个成音阶递进的立体声冒泡音效（`bubble-01..14.wav`）；`23.86s` 全部点亮后轨道以每帧 `0.42°` 缓慢空间自转，近端卡牌放大、远端缩小并降低不透明度；`25.03s`（`exitAt = 136`）阵列淡出，于 `25.43s` 完全清场。轨道只承载 Logo 与上屏名称，不叠分类胶囊、利益点长文或任何配置字段。
- **四拍能力全屏快切、品牌落定与 B 站三连星火收束（25.50–35.00s）**：`01/04 双语字幕`、`02/04 字幕导出`、`03/04 语音识别`、`04/04 联网搜索` 四拍全屏大字分别在 `26.00 / 26.50 / 27.00 / 27.50s` 抬升亮起，每拍只有一个编号、一个图标、一个四字词组和一行短注，并伴随逐级递增的 `pop.wav` 与和弦；`28.10s` 末拍向中心汇聚，`28.70s` 徽章胀开为 BiliScript 品牌图标与品牌名，`30.90s` 落出口号 *“在 B 站，读下一条视频。”*，`31.03s` 出现无框毛玻璃 Edge / GitHub 安装入口及下方高级灰辅文（`支持 Chrome / Edge 等 Chromium 内核浏览器 · 免费开源`）；`32.30s` 指针点击“Edge 应用商店”时迸发 B 站粉金双色几何“三连星火”粒子脉冲（`TripleLikeBurst`），`33.00s` 起进入最终定格到片尾。

## 混音与响度指标

- **配乐与动态**：120 BPM Tech Pop 原创合成（《BiliScript Pulse》，MIT License），按段落塑造动态包络（开场单句痛点克制 → 概览/对话稳健推进 → 外观/平台/四拍能力递进高潮 → 30.45–31.08s 收束留白 → 30.90s 品牌落定 → 33.0–35.0s 母带淡出）。
- **跨次元三幕真实讲课人声切入与闪避**：`5.60s`（`04:07` 原声回应，*“……也很难避免幻觉。”*）、`7.67s`（`02:32` 原声点题，*“如果他不答，一定是零分！”*）与 `15.30s`（`04:44` 原声举证，*“这里有一个研究……”*）切入原片真实讲课原声，配乐执行 `11.5 dB` 持续平滑闪避并抽稀中频打击乐与琶音；`1.70s` 镜头拉远、`2.53s` 横幅推进、`3.50 / 7.50 / 11.50 / 17.50 / 20.50 / 25.50s` 镜头切点与 `28.70s` 品牌落定叠加 `60–90Hz` 短促 Sub-hit，动作音效触发点执行 `2.5–6 dB` 预闪避。
- **成片音频硬指标**：综合响度 `-14.0 ± 0.5 LUFS`，动态范围 `LRA 4.0–6.0`，True Peak `≤ -1.0 dBTP`，无削波。
