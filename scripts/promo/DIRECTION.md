# BiliScript 宣传片方向

## 范围与叙事

1920×1080、30fps、33 秒，共 990 帧，中文横版产品宣传片。范围是浏览器扩展的 B 站视频字幕阅读、AI 概览、AI 对话、外观设置与 AI 平台预设；不扩展到其他产品平台。真实录屏保持功能含义和操作顺序，20–25 秒为 AI 平台预设镜头，25–33 秒为能力、品牌与安装收束。所有场景、字幕与 `audio.cues` 共用这条时间轴。

本文只记录创作方向与镜头意图。镜头帧区间以 `timeline.mjs` 和 `outro-timeline.mjs` 为准，声音事件以 `audio.mjs` 为准，字幕区间以 `captions.mjs` 为准；制作命令与产物位置见 `README.md`。

## 空间景深无框融合方向：全片晨读亮场空间（Morning Light Spatial）+ 跨次元三幕原声问答接龙 + 纸感翻页隐喻

采用 **无框空间景深融合（`fusion-light`）方案**：
- **全片晨读亮场基底（0–33s，`#FBFBFD → #F4F5F8`）**：全片保持清爽通透的晨读亮场空间底色与细腻漫反射光晕（`rgba(251, 114, 153, 0.055)` 与 `rgba(0, 174, 236, 0.045)`），彻底去除机械外框线（`1px/2px/3px solid`）、顶角方框标签与解释性说明副标，依靠 **Z 轴空间透视（`perspective(1600px)`、`rotateX`、`rotateY`）**、**多层漫反射阴影（`ELEVATION`）** 与 **毛玻璃悬浮层（`backdrop-filter: blur`）** 建立前后景深主次。
- **跨次元三幕原声问答接龙（`04:07` / `02:32` / `04:44` 跳播与点题锚点）**：保持 120 BPM 原创合成器纯音乐《BiliScript Pulse》与动作音效，围绕原片《大模型导论》赵斌老师的真实讲课原声建立“找现象 → 抓成因 → 问破局”三幕式问答接龙——在 `5.10s`（`SubtitleScene` 提问 *“记得老师提过「幻觉」，在哪一秒？”* 并点击 `04:07` 跳播）切入原声 *“……也很难避免幻觉。”*；在 `7.17s`（`OverviewScene` 提问 *“48 分钟公开课，AI 为什么爱犯幻觉？”* 呈现 `02:32` 核心论点卡）切入原声 *“如果他不答，一定是零分！”* 并衔接到 `8.73s` 包含该句原话的金句分享卡；在 `14.80s`（`ChatScene` 提问 *“既然难免幻觉，怎么选 AI 才对？”* 并点击 `(04:44–05:15)` 跳播）切入原声 *“这里有一个研究……”*。配乐同步执行 `6.5–8.5 dB` 平滑闪避，画面同步浮现无框毛玻璃声波条（`VoiceWaveBar`），让产品能力演变为与原片老师的跨次元对话。
- **「读视频」书页立体翻折与夜读台灯纸感隐喻**：片头在保留前景 `58px` 痛点三连问大卡的基础上，背景融入真实 B 站痛点弹幕（*“48 分钟太长了，课代表呢？求个省流总结！”* 等）与底部红色高能进度条焦虑快进，点击播放页下方“文摘”入口后，右侧 **文摘面板** 以左边缘为书脊执行 `rotateY(-34deg → 0deg)` 立体书页翻开展平，叠加书脊折痕阴影与细微纸张纤维肌理（`PaperGrainOverlay`），顶部横幅霸气回应弹幕：*“不用等课代表，在 B 站直接「读」视频。”*；金句卡片与外观切换均叠加纸感肌理、三维翻页微倾与温暖定向夜读台灯光束（`ReadingLampBeam`）。
- **严格对齐领域术语的明暗模式 × 外观色板空间预览（17–20s）**：不做整屏纯黑切色，始终保持晨读亮场空间底色；严格区分 `GLOSSARY.md` 定义的 **明暗模式**（`light` 浅色 | `dark` 深色）与 **外观色板**（`flyme` 蓝雾玻璃 | `editorial` 数字刊物）两条正交轴，顶部悬浮 `浅色 · 蓝雾玻璃` / `深色 · 夜读` / `数字刊物 · 暖纸衬线` 状态胶囊，左侧悬浮预览面配合翻页微倾、纸纤维纹理与暖调阅读台灯光晕同步切换。

### 关键手法与镜头锚点

- **黄金前 3 秒痛点弹幕 + 三连问叠卡 + 居中大字主张推镜聚焦（0.00–3.00s）**：0.00–1.40s（`frames 0..42`）以轻度柔化的 B 站公开课页面（`scale(1.34 → 1.30)`、`blur(4.5px)`）叠透光晨读薄纱、顶部真实痛点弹幕流与底部红色高能进度条快进为景深底，三张无框毛玻璃痛点问题卡分别在 `0.00s`（`frame 0`）、`0.43s`（`frame 13`）、`0.87s`（`frame 26`）同屏错峰弹簧入场；`1.20–1.43s`（`frames 36..43`）三张问题卡向纵深坍缩退场，镜头急速拉远合焦；`1.40s`（`frame 42`）指针点击播放页下方“文摘”入口按钮并泛起粉色脉冲，右侧 **文摘面板** 在 `1.40–1.87s`（`frames 42..56`）沿书脊折痕以 `rotateY(-54deg → 0deg)` 书页翻折展开，同时核心主张 `BiliScript · 不用等课代表，在 B 站直接「读」视频。` 先在画面中央偏左大字浮现（`frames 42..56`），再在 `1.87–3.00s`（`frames 56..90`，总停留 `1.60s`）顺滑归位至左上角并同步推镜（`Zoom-in 1.0x → 1.35x`）聚焦右侧 `BiliScript` 文摘面板。
- **第一幕问答·搜索词切片与机械键盘回车（3.00–3.87s）**：顶部标题带抛出问题 *“记得老师提过「幻觉」，在哪一秒？”*；“幻觉”只做一次横向切片错位与聚合，错位 2–3 帧、归位 6–8 帧，随后同一个词连续缩进真实搜索框，配合双键清脆机械轴敲击声与 `3.73s` 回车键平衡杆触发反馈（`mech-key-1/2` + `mech-enter`）。
- **磁吸吸附瞬移与 `04:07` 原声回应（5.00–7.00s）**：以实际选中的字幕条目和真实时刻文本 `4:07` 为匹配剪辑锚点，在 `5.03s`（`frame 151`）触发磁吸吸附音效（`snap.wav`）与画面高光瞬移缩放，伴随无框毛玻璃 `TimestampMatchCallout` 抬升；`5.10s`（`frame 153`）切入赵老师真实讲课原声回应 *“……也很难避免幻觉。”*（`1.60s`），播放器随人声泛起柔和粉色环境光晕，顶部浮现动态声波验证条 `04:07 · 赵老师原声回应 · “……也很难避免幻觉。”`。
- **第二幕问答·Z 轴章节抽层原声点题与金句纸感快门切换（7.00–11.00s）**：7.00–8.73s 左侧标题提问 *“48 分钟公开课，AI 为什么爱犯幻觉？”*，下方采用三层 Z 轴空间叠放——`00:00` 与 `04:27` 章节行后退柔化，`02:32` 核心论点卡向前抬升并叠加纸纤维纹理；`7.17s`（`frame 215`）切入赵老师真实讲课原声点题 *“如果他不答，一定是零分！”*（`1.45s`），紧接着在 `8.73s`（`frame 262`）将包含这句原话的真实字幕段抬升为前景无框分享金句卡（*“他只要去答这个题目，得的就不是零分，但是他如果不答一定是零分……”*），叠加纸张肌理（`PaperGrainOverlay`）与暖调台灯光束（`ReadingLampBeam`），并在 `9.20s / 9.43s / 9.83s` 每次切换配色时触发成音阶递进的水滴快门声（`shutter-1..3.wav`）与三维翻页微倾。
- **面板失焦（10.80–11.23s 与 16.80–17.23s）**：分别接续金句→AI 对话、AI 对话→外观设置。旧主体失焦退场 6 帧，干净切点，新主体合焦 7 帧。
- **第三幕问答·AI 对话时间戳同屏跳播与 `04:44` 原声举证（11.00–17.00s）**：左侧标题追问 *“既然难免幻觉，怎么选 AI 才对？”* 并悬浮问题卡（*“为什么作者说 AI 并非越强越好，适配才是关键？”*），右侧无框悬浮对话主体卡展示结构化回答；13.80s（全局 `frame 414`）指针移动并点击回答中的 `(04:44–05:15)` 时间戳；14.80–15.80s 同屏展示左侧已跳播至 `04:44` 的原片播放器与右侧总结面板，同步切入赵老师真实讲课原声举证 *“这里有一个研究……”*（`1.35s`）与声波条 `04:44 · 赵老师原声举证 · “这里有一个研究 · 人机协作象棋实验”`，15.80–17.00s 回到总结要点收束。
- **明暗模式 × 外观色板空间预览与夜读台灯（17.00–20.00s）**：保持晨读亮场背景，顶部右侧悬浮 `浅色 · 蓝雾玻璃` / `深色 · 夜读` / `数字刊物 · 暖纸衬线` 状态胶囊；右侧展示真实外观设置面板，左侧悬浮预览面伴随三维翻页微倾、纸感肌理与暖调阅读台灯光束（`ReadingLampBeam`）依次切换为深色夜读磨砂界面与暖棕衬线数字刊物界面。
- **平台预设满幅出血、单一连续 `14` 计数与琴键波浪冒泡矩阵（20.00–25.00s）**：20.00–21.73s 右侧以 `1080px` 宽（占屏宽 `56.25% ≥ 55%`）无框空间悬浮展示“添加 AI 平台”预设弹窗（无任何 API Key 或敏感字段）；20.73s（`countAt = 22`）左侧亮出 `168px` 的 `14 个 AI 平台预设` 并静止停留 `22` 帧（`0.73s ≥ 0.65s`），随后在 `frames 44..58` 由同一组件连续平移缩放至顶部居中；14 家官方 Logo 无框毛玻璃卡（`224×226`）自 `wallAt = 52`（`21.73s`）起对齐 120 BPM 十六分音符鼓点（`cardStagger = 3.75` 帧），以多米诺骨牌/琴键弹起的三维波浪动效错峰跃起，并叠加 14 个成音阶递进的立体声冒泡音效（`bubble-01..14.wav`），在 `collapseAt = 136` 向画面中心径向汇聚，于 `24.93s` 完全清场。
- **无框能力卡微缩预览、音乐急停与 B 站三连星火收束（25.00–33.00s）**：四张 `400×360` 无框毛玻璃能力大卡（双语字幕 / 字幕导出 / 语音识别 / 联网搜索）内嵌微缩 UI 视觉预览，分别在 `25.50 / 26.00 / 26.50 / 27.00s` 按拍抬升亮起并伴随逐级递增的音效与和弦；`28.67s` 四卡向中心汇聚同时配乐急停留白，`29.20s` 图标清晰落定并触发 Resolve 和弦，随后展开品牌名、口号 *“在 B 站，读下一条视频。”* 与无框毛玻璃 Edge / GitHub 安装入口；`30.60s` 指针点击“Edge 应用商店”时迸发 B 站粉金双色几何“三连星火”粒子脉冲（`TripleLikeBurst`）。

## 混音与响度指标

- **配乐与动态**：120 BPM Tech Pop 原创合成（《BiliScript Pulse》，MIT License），按段落塑造动态包络（片头克制 → 概览/对话稳健推进 → 外观/平台/四拍能力递进高潮 → 28.67s 急停呼吸 → 29.20s 品牌落定 → 31–33s 淡出）。
- **跨次元三幕真实讲课人声切入与闪避**：`5.10s`（`04:07` 原声回应，*“……也很难避免幻觉。”*）、`7.17s`（`02:32` 原声点题，*“如果他不答，一定是零分！”*）与 `14.80s`（`04:44` 原声举证，*“这里有一个研究……”*）切入原片真实讲课原声，配乐执行 `6.5–8.5 dB` 持续平滑闪避；8 个核心转折与切点（含 `1.80s` 镜头拉远切入点）叠加 `60–90Hz` 短促 Sub-hit，动作音效触发点执行 `2.5–6 dB` 预闪避。
- **成片音频硬指标**：综合响度 `-14.0 ± 0.5 LUFS`，动态范围 `LRA 4.0–6.0`，True Peak `≤ -1.0 dBTP`，无削波。
