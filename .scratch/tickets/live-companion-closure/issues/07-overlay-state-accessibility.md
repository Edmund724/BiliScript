# 07: 伴看浮窗状态与可访问性

**What to build:** 伴看浮窗在活跃态只有展开和迷你胶囊两种呈现，不会出现“连接仍在但浮窗完全消失”的第三态。迷你胶囊用文本说明正在伴看、连接中、重连中或需要处理；展开、最小化和失败处理都有清晰的焦点与无障碍语义。

**Blocked by:** 01: 独立伴看会话与播放器入口

**Status:** closed

- [x] 活跃态收起只进入迷你胶囊；完全隐藏只随空闲或显式结束发生
- [x] 迷你胶囊提供状态文本和麦克风静音状态，不再只有圆点和图标
- [x] 点击胶囊只展开，不挂断；展开后焦点落在合理位置，最小化后焦点回到胶囊
- [x] 展开态和迷你态暴露正确的 `aria-expanded`、`aria-controls` 与可读名称
- [x] 需要处理的失败会展开错误卡；处理完成后尊重用户上次选择的迷你态
- [x] 键盘可完成展开、最小化、静音和结束，不依赖拖拽或精确点击
