# 05: 完成外观场景并统一镜头动效

**What to build:** 外观段落清楚演示深色模式与外观色板，主要功能镜头形成一致的局部放大、镜头跟随、微 3D 和弹簧转场语言。观众的注意力随当前操作移动，而不是持续观看文字过小的全景面板。

**Blocked by:** 02: 用真实 B 站页面重做片头 Hook；03: 打通字幕搜索到原片跳播的镜头闭环；04: 拆清章节概览与金句卡片

**Status:** ready-for-agent

- [ ] 深色模式切换动作与切换后的完整面板状态清晰可见，外观色板变化不与明暗模式混为一谈。
- [ ] 搜索、字幕点击、金句配色、AI 对话和外观操作均有与当前控件一致的镜头聚焦，近景不裁掉目标文字或反馈。
- [ ] 局部操作中的面板采用克制的约 5°–8° Y 轴微透视，文字仍清晰，无过度倾斜或视觉炫技。
- [ ] 主要内容场景的左右布局切换使用带轻微惯性回弹的弹簧运动，不出现生硬的匀速平移。
- [ ] 镜头运动、字幕和UI操作保持同步，全景与近景交接无跳帧、黑帧或突然错位。
- [ ] 完整粗剪回放与关键帧检查通过，并保留动效验收证据。
