# 03: 打通字幕搜索到原片跳播的镜头闭环

**What to build:** 观众能清楚看到在字幕中搜索“幻觉”、获得匹配结果、跟随高亮字幕点击时间戳，并在同一叙事镜头里看到 B 站播放器跳到对应真实画面，完整理解“找到那句，回到那一秒”。

**Blocked by:** 01: 重排为 28 秒粗剪

**Status:** ready-for-agent

- [ ] 搜索阶段以约 200% 局部推近呈现搜索框，输入“幻觉”的过程、`1/7` 匹配计数和高亮结果清晰可读。
- [ ] 镜头随指针下移至目标高亮字幕，目标时间戳和点击动作可辨认。
- [ ] 点击时通过拉远或分屏同时保留字幕操作与 B 站播放器反馈，播放器在点击后呈现目标时刻的真实不同画面。
- [ ] 搜索词、匹配数量、字幕内容和跳播结果来自同一次真实录制，不用无关画面拼接伪造联动。
- [ ] 既有素材不满足指定关键词、计数、联动或流畅度时，完成字幕段针对性补录。
- [ ] 镜头字幕与新版时间轴一致，试渲染与完整回放检查通过。
