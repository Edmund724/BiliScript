# 08: 渲染并验收正式发布工件

**What to build:** 生成可发布的正式宣传片及配套封面、中文字幕和 credits，并以真实完整播放和可重复生成的证据确认画面、声音、时长、可读性、清洁度与授权全部达到发布要求。

**Blocked by:** 07: 更换 BGM 并完成 UI 音效与混音

**Status:** ready-for-agent

- [ ] 正式成片为 1920×1080、30fps、H.264 视频与 AAC 音轨，时长处于 25–30 秒且目标为 28 秒，并启用 fast-start。
- [ ] 正式 MP4、封面、简体中文字幕和 credits 均从最终版本重新生成，不混用草稿或旧时间轴工件。
- [ ] 完整真实播放至结束，解码、音轨和定位检查通过，无黑帧、缺音、异常静止或字幕越界。
- [ ] 以 360px 宽手机等效预览检查关键镜头，搜索词、匹配计数、章节标题、配色操作和 CTA 均可辨认。
- [ ] 逐项确认片头与概览不重复、字幕点击具有播放器跳播反馈、AI 无长时间等待、最终定格仅 3–4 秒。
- [ ] 全片无账号信息、推荐内容或广告；演示来源署名复旦赵斌，音乐与音效许可和 credits 一致。
- [ ] 保留最终元数据、关键帧、完整回放结果及其他可重复生成的发布验收证据。
