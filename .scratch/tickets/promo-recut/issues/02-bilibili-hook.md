# 02: 用真实 B 站页面重做片头 Hook

**What to build:** 片头约 4 秒内，观众先看到真实 B 站视频播放页，再看到指针点击页面内“文摘”按钮、文摘面板顺滑展开，最后落到“在 B 站，读视频”的品牌口号。片头独立承担产品引入，不提前演示金句卡片。

**Blocked by:** 01: 重排为 28 秒粗剪

**Status:** ready-for-agent

- [ ] 首帧为可辨识的 B 站视频播放页，可按需要做背景柔化，但播放器和页面内“文摘”按钮可辨认。
- [ ] 指针点击页面内“文摘”按钮后，文摘面板以顺滑的展开动画出现，并清晰展示“在 B 站，读视频”。
- [ ] 片头不使用金句分享或配色画面，也不与后续概览镜头重复使用同一段录屏。
- [ ] 画面不暴露账号头像、推荐内容或广告；裁切、遮罩或补录后均无清洁度问题。
- [ ] 面板展开和文字在目标时长内清楚可读，放大后无明显截帧卡顿；既有素材不达标时完成针对性补录。
- [ ] 片头字幕与新版镜头同步，试渲染和完整回放检查通过。
