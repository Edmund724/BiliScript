# 07: 更换 BGM 并完成 UI 音效与混音

**What to build:** 成片使用具有明确许可的现代科技感、律动型背景音乐，主要切点与重拍一致；搜索输入、卡片与配色、深色模式和转场具有精细且同步的声音反馈，整体听感紧凑而不过载。

**Blocked by:** 05: 完成外观场景并统一镜头动效；06: 重做卖点揭示与片尾 CTA

**Status:** ready-for-agent

- [ ] 新 BGM 属于 Tech Pop、Upbeat Lo-Fi 或相近的轻快科技感风格，不再使用《Wholesome》，使用许可与署名信息完整。
- [ ] 按最终时间轴将主要场景切点安排在可辨识的重拍上，不沿用旧成片的绝对时间点。
- [ ] 输入“幻觉”时具有清脆键盘音，金句卡片弹出和配色切换具有轻微 Pop 类反馈。
- [ ] 深色模式切换具有利落的开关音，主要左右转场具有柔和 Whoosh，声音均与对应操作同帧起音。

- [ ] 发布 credits 同时覆盖 BGM 与全部非自制音效的来源和许可，完整音轨通过回放检查。
