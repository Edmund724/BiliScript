# 01: 重排为 28 秒粗剪

**What to build:** 观众可以完整观看一支目标 28 秒的粗剪版宣传片。各功能段落连续衔接，AI 追问不再展示真实长时间等待，片尾只保留必要停留，字幕与新时间轴一致。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 粗剪总时长以 28 秒为目标，并处于 25–30 秒范围内。
- [ ] 保留片头、字幕、概览、AI 对话、外观和片尾的完整叙事顺序。
- [ ] AI 提问发送后，保留约 0.5 秒“思考中”与英文推理闪动，随后直接呈现完整回答，没有数秒等待空档。
- [ ] 片尾最终定格为 3–4 秒，不出现额外长时间静止。
- [ ] 所有字幕起止时间落在新版对应镜头内，无重叠、越界或沿用旧时间码。
- [ ] 试渲染与完整回放检查通过，并生成对应关键帧和时长证据。
