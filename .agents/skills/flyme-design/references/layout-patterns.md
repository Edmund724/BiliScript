# Flyme 布局模式与适配

## 页面骨架

沉浸式状态栏（内容延伸其下）→ 导航 48（透明 → 滚动后毛玻璃）→ 内容区（边距 16）→ 标签栏 64 + 安全区。栏与内容间无分隔线。

## 典型页面

**设置页**：胶囊搜索 → 分组卡片列表。首组常为账号卡（头像 48 圆 + 昵称 + chevron）。

**个人中心**：留白头部 32 + 头像 64 圆 + 昵称 Title 20 → 彩色宫格（每行 4，容器 48 / 圆角 14）→ 分组卡片列表。

**内容列表**：单列白卡 feed（组间 12）或双列瀑布（间距 12）。下拉刷新 56；50 条以上虚拟滚动。

**控制 / 通知中心**：顶部下拉全屏毛玻璃面板，呼出分区（独立面板：左侧约 3/4 通知、右侧约 1/4 控制；上滑收起）。通知卡堆叠，任务型用实况通知。负一屏为 20 大圆角内容卡。

**Aicy 面板**：流光背景 → 建议胶囊行 → 聆听条 → 问屏入口 → 模式白卡。流光不复用于其他页面。

**外观 / Alive 壁纸**：超大 Display Light 时钟 + 浓彩渐变壁纸；下滑 / 收起面板时光晕跟手渐变（跟手阶段无 transition，松手 300ms 回稳）。营销介绍页可用淡彩底 + `--ai-text` 大标题，系统功能页守中性底。

**空状态**：小圆圈插画（约 120px SVG）+ Caption 说明 + 胶囊主按钮，间距 16。

## 断点与降级

| 断点 | 宽度 | 布局 |
|------|------|------|
| Compact | < 600dp | 标签栏，1–2 列 |
| Medium | 600–839dp | 侧边栏 + 内容 |
| Expanded | ≥840dp | 侧边栏 + 双栏 |

核心交互 60fps；每屏毛玻璃 ≤4 层、blur ≤30px，不支持或低端机退化 0.95 纯色；`prefers-reduced-motion` 退化 ≤100ms fade；图片占位 → 缩略图 → 原图。
