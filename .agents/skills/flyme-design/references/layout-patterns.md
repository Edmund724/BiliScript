## 一、页面骨架

自上而下：沉浸式状态栏（内容延伸其下）→ 导航栏 48px（透明 → 滚动后毛玻璃）→ 内容区（16px 水平边距）→ 底部标签栏 64px + 安全区。栏与内容之间无分隔线。

## 二、典型页面模式

### 设置页（最典型）

顶部可选胶囊搜索框 → 分组卡片列表（见 components.md 二）。首组常为账号卡：头像 48 圆形 + 昵称 + 说明 + chevron。功能行左侧图标一律彩色容器。

### 个人中心

留白头部（32px）+ 头像 64 圆形 + 昵称（Title 20）+ 简介（Caption）→ 彩色功能宫格（每行 4 个，容器 48/圆角 14，每项一色）→ 分组卡片列表。

### 内容列表页

单列白卡 feed（组间 12）或双列瀑布（列间/行间 12）。下拉刷新阈值 56dp；分页 20–50 条；50 条以上虚拟滚动。

### 控制中心 / 通知中心（标志性，值得单独出 demo）

顶部下拉的全屏毛玻璃面板（真机左右下拉分别对应通知/控制，原型可合并演示）：
- 顶部超大时钟（Light 字重）+ 日期
- 主区：左列白色圆角卡叠放 WLAN/移动数据/蓝牙 三行（彩色圆形 chip + 状态 + 展开箭头），右列亮度/音量两根竖向胶囊滑条
- 下方圆角方形小磁贴网格（每行 4 个），激活态填充功能色
- 通知中心：白色圆角通知卡堆叠（任务型用实况通知，见 components.md 十八）；负一屏纵览为 20px 大圆角内容卡（时钟/天气/步数/媒体播放卡，媒体卡可用深色底）

### Aicy 唤醒面板（AIOS 2 标志性，见 components.md 十七）

全屏 AI 场景面板：蓝紫流光光晕背景 → 白色建议胶囊行 → 聆听条（紫色声浪点）→ 模式选择白卡。系统内唯一允许大面积彩色的界面，流光背景禁止在其他页面复用。

### 智慧生活 / 设备互联页

低饱和浅底（#EAF0F6 级）→ 大标题 → 设备白卡网格（每行 2 列、圆角 20：设备符号 + 名称 + 状态）+ 圆形主蓝开关 chip；底部标签栏。与设置页的区别：无分组标题，卡片更扁更方。

### 锁屏 / Alive 壁纸（AIOS 2，可选演示）

超大时钟（Display Light）置于浓彩渐变壁纸上；「多彩相框」「时间故事」属壁纸层样式，原型以渐变底 + 大时钟示意即可。

### 空状态

小圆圈构图插画（SVG 约 120px）+ Caption 说明 + 胶囊主按钮，元素间距 16。

## 三、安全区域

| 区域 | 数值 |
|------|------|
| 状态栏 | 沉浸式；Web 原型用 env(safe-area-inset-top)，纯演示可固定 28px |
| 导航栏 | 48px |
| 底部手势区 | 48px，底部固定元素必须 inset 避让 |

## 四、响应式断点

| 断点 | 宽度 | 布局 |
|------|------|------|
| Compact | < 600dp | 底部标签栏，1–2 列卡片 |
| Medium | 600–839dp | 侧边栏 + 内容区 |
| Expanded | ≥840dp | 侧边栏 + 双栏内容 |

横竖屏切换保持数据状态。魅族无折叠屏设备，可不覆盖折叠态。

## 五、排版与内容约束

- 文本截断默认末尾省略号；文件名类中间截断
- 列表标题/副标题各最多 2 行；卡片摘要 2 行截断 + 展开
- 正文支持字体缩放；长文自然换行

## 六、性能与降级

- 核心交互 60fps；backdrop-filter 每屏 ≤4 层、blur ≤30px；不支持或低端设备退化为 0.95 不透明纯色
- prefers-reduced-motion: reduce 必须实现（动效退化为 ≤100ms fade）
- 图片三级加载：占位色块 → 200px 缩略图 → 原图；内存 + 磁盘双缓存
- 50 条以上列表虚拟滚动；绘制回调中不改布局；背景重叠 ≤2 层
