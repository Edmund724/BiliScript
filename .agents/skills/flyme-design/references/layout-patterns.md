## 一、页面骨架

自上而下：沉浸式状态栏（内容延伸其下）→ 导航栏 48px（透明 → 滚动后毛玻璃）→ 内容区（16px 水平边距）→ 底部标签栏 64px + 安全区。栏与内容之间无分隔线。

## 二、典型页面模式

### 设置页（最典型，AIOS 已归纳路径）

顶部可选胶囊搜索框（支持拼音字母及首字母搜索）→ 分组卡片列表（见 components.md 二）。首组常为账号卡：头像 48 圆形 + 昵称 + 说明 + chevron。功能行左侧图标一律彩色容器。

归纳路径（原型信息架构照此）：存储和备份、系统更新 → 我的手机；查找手机、紧急求助、地震预警、家庭守护、屏幕共享保护 → 安全；语言和时间 → 通用；NFC → 更多连接方式；定位服务 → 权限和隐私；息屏/锁屏拆分至个性化、显示、通用；导航与快捷操作拆分至通用、辅助功能。部分页面带「相关设置」快捷入口。新增用机引导（按旧机习惯初始化 + 特色功能引导）。

### 个人中心

留白头部（32px）+ 头像 64 圆形 + 昵称（Title 20）+ 简介（Caption）→ 彩色功能宫格（每行 4 个，容器 48/圆角 14，每项一色）→ 分组卡片列表。

### 内容列表页

单列白卡 feed（组间 12）或双列瀑布（列间/行间 12）。下拉刷新阈值 56dp；分页 20–50 条；50 条以上虚拟滚动。

### 控制中心 / 通知中心（标志性，Flyme 12.5 改版后值得单独出 demo）

顶部下拉的全屏实时毛玻璃面板：
- 呼出手势：独立面板时桌面左侧约 3/4 下滑呼出通知中心、右侧约 1/4 呼出控制中心；经典面板下滑呼出合并面板；任意位置一次上滑收起
- 顶部超大时钟（Light 字重）+ 日期
- 主区：左列白色圆角卡叠放 WLAN/移动数据/蓝牙 三行（彩色圆形 chip + 状态 + 展开箭头），右列亮度/音量两根竖向胶囊滑条（音量条拉伸动效）
- 下方圆角方形小磁贴网格（每行 4 个），激活态填充功能色；全自定义 + 分页（见 components.md 八）
- 通知中心：白色圆角通知卡堆叠（任务型用实况通知：状态栏胶囊常驻 + 点击悬浮展开，见 components.md 十八）；负一屏纵览为 20px 大圆角内容卡（时钟/天气/步数/媒体播放卡，媒体卡可用深色底；第三方插件规范化尺寸，支持堆叠滑动切换）
- 桌面：插件支持同尺寸堆叠滑动切换；锁定布局后禁移动/加插件/卸载；下滑呼出可配搜索或通知和控制中心；应用分身分层图标 + 打开退出平滑过渡；Flyme 风格图标/插件开关

### Aicy 唤醒面板（AIOS 2 标志性，见 components.md 十七）

全屏 AI 场景面板：蓝紫流光光晕背景（呼吸感灵动）→ 白色建议胶囊行 → 聆听条（紫色声浪点）→ 问屏入口 → 模式选择白卡。系统内唯一允许大面积彩色的界面，流光背景禁止在其他页面复用。

### 系统外观中心 / Alive 壁纸（AIOS 必备，单独出 demo 时优先）

【官方：外观中心全新升级；Alive 壁纸跟手渐变；多组息屏+锁屏+桌面组合；长按锁屏/通知中心空白处预览切换；锁屏时间字体多款、大小可调、日期在时间上方；自选壁纸长虹/波浪/雾花纹理滤镜 + 亮屏纹理叠加动画；摩登时代/个性自我顶部自动扩图；多彩相框/时间故事/时间之美】

- 入口：系统设置 → 桌面 → 壁纸和个性化 → 壁纸；文字壁纸归纳至 Alive 壁纸
- 编辑条在底部：左钮选图/息屏样式，右钮选息屏风格/壁纸效果；半屏编辑页横滑切换
- 组合：支持保存多组息屏 + 锁屏 + 桌面组合，长按锁屏或通知中心空白处预览、随心切换
- 锁屏：超大时钟 Display Light 置于浓彩渐变/纹理壁纸上；多款时间字体，大小可调，日期在时间上方
- 壁纸动效：下滑/收起通知面板时 Alive 光晕跟手渐变；亮屏时纹理叠加动画；原型以渐变底 + 大时钟 + 跟手位移示意即可

### AI 功能介绍流（发布会海报页 · 读图新增，原型营销页照此）

【读图：浅薰衣草/淡青整页底 + 白大卡 20–24px；超大渐变标题（紫→粉→橙，30–40px ExtraBold）；渐变描边胶囊 pill；手机真机图内嵌；底部红底机型条】

- 背景：淡彩整页（`--tint-lavender`/mint/blue 轮换），非中性灰
- 标题：超大渐变字 `--ai-text`（紫左橙右）+ 顶部渐变描边胶囊 `--ai-pill-line`
- 内容卡：白底 20–24px 圆角，内边距 20；小节标题渐变字 17px Bold（如「三指截图收藏」）
- 真机图：圆角 16 内嵌，状态栏小字 + 底部白色工具条（圆形 icon 钮 + 「拖拽给 Aicy」pill）
- 例外声明：营销页允许大标题与淡彩底，系统功能页仍守中性底 + 小标题规范

### 智慧生活 / 设备互联页

低饱和浅底（#EAF0F6 级）→ 大标题 → 设备白卡网格（每行 2 列、圆角 20：设备符号 + 名称 + 状态）+ 圆形主蓝开关 chip；底部标签栏。与设置页的区别：无分组标题，卡片更扁更方。

### 锁屏 / Alive 壁纸（AIOS 2，可选演示）

见上节「系统外观中心 / Alive 壁纸」。极简示意：超大时钟（Display Light）+ 浓彩渐变壁纸 + 跟手渐变；「多彩相框」「时间故事」属壁纸层样式，原型以渐变底 + 大时钟示意即可。

### 空状态

小圆圈构图插画（SVG 约 120px）+ Caption 说明 + 胶囊主按钮，元素间距 16。

## 三、安全区域

| 区域 | 数值 |
|------|------|
| 状态栏 | 沉浸式；Web 原型用 env(safe-area-inset-top)，纯演示可固定 28px |
| 导航栏 | 48px |
| 底部手势区 | 48px，底部固定元素必须 inset 避让 |

## 四、响应式断点

| 断点 | 宽度 | 布局 |
|------|------|------|
| Compact | < 600dp | 底部标签栏，1–2 列卡片 |
| Medium | 600–839dp | 侧边栏 + 内容区 |
| Expanded | ≥840dp | 侧边栏 + 双栏内容 |

横竖屏切换保持数据状态。魅族无折叠屏设备，可不覆盖折叠态。

## 五、排版与内容约束

- 文本截断默认末尾省略号；文件名类中间截断
- 列表标题/副标题各最多 2 行；卡片摘要 2 行截断 + 展开
- 正文支持字体缩放；长文自然换行

## 六、性能与降级

- 核心交互 60fps；backdrop-filter 每屏 ≤4 层、blur ≤30px；不支持或低端设备退化为 0.95 不透明纯色
- prefers-reduced-motion: reduce 必须实现（动效退化为 ≤100ms fade）
- 图片三级加载：占位色块 → 200px 缩略图 → 原图；内存 + 磁盘双缓存
- 50 条以上列表虚拟滚动；绘制回调中不改布局；背景重叠 ≤2 层
