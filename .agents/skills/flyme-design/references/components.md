## 一、沉浸式导航栏

- 内容延伸到状态栏之下（沉浸式状态栏）；导航高 48px，标题居中 17px/Medium
- 初始透明；滚动后切换为毛玻璃 + 发丝线（浅色 rgba(0,0,0,0.05) / 深色 rgba(255,255,255,0.06)）
- 左右操作热区 40×40；返回键为圆形热区 + stroke 2 箭头
- 按压：图标不透明度 60%

## 二、分组卡片列表（设置页核心）

- 组 = 圆角 16 卡片（浅 #FFFFFF / 深 #1B1C20），页面边距 16，组间 12
- 行高 56：彩色圆形图标 chip 40×40 + 间距 16 + 标题 16px/Regular（可选副标题 12px）
- 右侧：值文字（15px 次色）/ 开关 / chevron（#C3C6CC，stroke 2）
- 组内默认无分隔线（去线留白）；行数 >6 用发丝线，左缩进 72px
- 按压：行背景加深（浅 rgba(0,0,0,0.04) / 深 rgba(255,255,255,0.05)），圆角 12
- 左滑露出操作（阈值 40dp）；长按 500ms 上下文菜单；下拉刷新阈值 56dp

## 三、按钮（胶囊）

- 高 44（大 48 / 小 36）；圆角 = 高度一半
- 主：主色底白字；次：主色浅底 + 主色字；文字按钮：主色字
- 按压 scale(0.97) + 颜色加深一档；禁用 40% 不透明度
- 加载态：小圆圈 spinner 替换文字，保持原宽度

## 四、输入框

- 高 48、圆角 12、filled 底色（浅 #F0F1F3 / 深 #222327），无边框
- 聚焦：浅色变白底 + 1.5px 主色描边；深色保持深底 + 描边；字 15px
- 搜索框：胶囊 + 灰底 + 放大镜图标

## 五、开关

- 51×31 胶囊；开启主色 / 关闭 #E3E4E8（深 #3A3B40）；滑块 27px 纯白；250ms

## 六、胶囊滑条（亮度/音量/进度）

- 高 36 胶囊；轨道 #E8E9ED（深 #2A2B30）；填充主色
- 横向纯展示型（亮度/音量）：无把手；可调型：24px 白色圆形把手
- 按压调节带拉伸动效：条体沿调节方向弹性拉长 4–8px 后 200ms 回位（Flyme 12.5 音量条特性，Web 用 scaleY/scaleX 近似）
- 竖向（控制中心亮度/音量）：白卡底胶囊，约 76×150、圆角 24，自底部彩色填充，22px 白色图标居中于填充区

## 七、卡片

- 圆角 16、内边距 16–20；标题 1–2 行、描述 2–3 行截断；图片比例 16:9 / 4:3
- 静态卡片零阴影（灰底白卡已分层）；仅浮起卡片用轻阴影

## 八、控制中心（标志性，Flyme 12.5 全面改版后）

【官方：控制中心全新改版——全自定义布局、分页摆放、经典面板实时动态模糊、控件圆角与模糊优化、快捷开关/展开收起動效优化；桌面下滑分区呼出；横屏独立布局横滑；新增投屏/录音/计算器快捷】

全屏实时毛玻璃背景上，自上而下：

- 顶部：超大时钟（Display 字阶 Light）+ 日期 Caption（日期在上、时间在下为锁屏样式，控制中心保持时钟+日期同行区）；右上角设置/宫格入口
- 呼出：桌面下滑新增选项——独立面板时左侧约 3/4 区域下滑呼出通知中心、右侧约 1/4 呼出控制中心；经典面板下滑呼出合并面板；任意位置一次上滑收起。原型合并演示时保留分区提示。
- 主区三列：左侧白色圆角卡（20px）叠放 WLAN / 移动数据 / 蓝牙 三行——彩色圆形 chip 36 + 名称 14px/Medium + 状态 11px + 展开箭头，关闭项 chip 为中性灰；点击已连接蓝牙可快速断开；右侧亮度、音量两根竖向胶囊滑条并排（音量条带拉伸动效）
- 下方：小磁贴网格，每行 4 个、约 72×72、圆角 20（圆角与模糊按 12.5 优化值微调，原型沿用 20）、gap 12——未激活 = 白底 + 中性灰 glyph + 11px 标签；激活 = 功能色填充 + 白 glyph（自动亮度琥珀、超级互连主蓝等，按功能取色）；新增投屏磁贴（Miracast，点击已连接设备断开）
- 自定义与分页（12.5 核心）：所有控件可自由添加/删除/移动；支持分页摆放容纳不同数量组件；原型至少演示两页 + 编辑态（长按抖动/拖拽示意），静态单页即视为未对齐 AIOS 2
- 横屏：独立控制中心横向排布、支持横滑切换位置（原型横屏演示时切换为横向网格）
- 点按：180ms scale(0.95) + 颜色翻转；展开/收起 320ms 可打断 + 结尾轻微物理回弹

## 九、通知卡片

- 白卡圆角 16，堆叠 gap 8，置于毛玻璃面板上
- 结构：应用彩色图标 20 + 应用名 12px + 时间 + 标题 15px/Medium + 内容 15px 次色（2 行截断）
- 左滑消除；点击进入应用
- 任务型通知（AI 收藏/AI 生成/互连任务）改用实况通知样式（见十八）

## 十、弹窗

- 原生 `<dialog>` + `showModal()`；宽 ≤320px、圆角 24；标题 17px/Medium 居中、内容 15px 居中
- 操作区：双胶囊按钮横排（次 = 主色浅底、主 = 主色），高 44
- 入场 250ms scale(0.94→1) + fade（@starting-style + allow-discrete）；退场对称
- 关闭：`closedby="any"` 点遮罩 + Esc；无支持浏览器用 JS 回退（点击落在 dialog 内容框外即关闭）
- 必备 aria-labelledby

## 十一、底部面板

- 顶部圆角 24 + 拖拽条（36×4、圆角、#D5D7DB）
- 上滑展开 320ms；下滑或点遮罩关闭

## 十二、Toast

- 深色胶囊（rgba(29,30,34,0.92)，深浅通用，可选 blur）；白字 14px
- 底部居中、上移 120px；2s 自动消失

## 十三、底部操作条（替代 FAB）

- 表单/详情页：固定底部全宽胶囊主按钮，左右边距 16 + 底部安全区避让
- 背景向下渐隐（或毛玻璃条）
- Flyme 不使用悬浮 FAB——发现自己在画 FAB 即跑偏

## 十四、底部标签栏

- 高 64 + 底部安全区；毛玻璃背景
- 图标 24（线性 → 选中填充 + 主色）；文字 11px
- 标签切换 250ms fade

## 十五、Aicy 管家简报卡（AIOS 2：Aicy 管家）

- 白卡圆角 16：头部 = Aicy 原子花渐变 logo 24 + 「Aicy 管家」15px/Medium + 右侧场景标签 11px（`--ai-text` 渐变文字）
- 简报行 2–4 条：功能色线性图标 20 + 主文字 15px + 次级说明 12px；内容随场景智能变化（天气交通/日程/运动/记忆聚合/电量与玩机手册推荐）
- 数据来源行 11px 次色（如「根据你的日程与实时天气智能生成」）
- 十二时辰插件（Flyme 12.5 新增）：显示当前时辰与时刻，与简报卡同视觉、可独立成卡
- 横滑子卡片列（宽 140、gap 12）可选；卡片入场 40ms stagger

## 十六、小圆圈（品牌符号）

- 加载 spinner：24px 圆环、stroke 2、主色、旋转——全系统唯一允许的旋转动效
- 空状态/指纹解锁等插画以圆环、圆点构图（SVG，约 120px）

## 十七、Aicy 唤醒面板（AIOS 2 标志性：呼吸感更灵动）

【官方：全新 Aicy——呼吸感灵动设计，接入 Qwen Omni 超自然语音（百变音色/方言）+ DeepSeek 深度思考；问屏一句话识别总结比价；识屏小窗打开；双击电源键识屏；拖拽分享视觉动效；锁屏可呼出查看时间通知】

AI 场景唯一允许大面积彩色的界面：

- 背景：`--ai-glow` 蓝紫流光光晕铺满面板（大圆角 28）+ 4–6s 呼吸位移；组件全部白底浮于光晕之上；prefers-reduced-motion 下光晕静态化
- 顶部建议胶囊行：白底胶囊、16px/Medium 深字、gap 12（如「关机/重启」「网址解读」；Beta 类标签用主色浅底小 chip）
- 聆听条：白胶囊（高 64）：左 × 圆钮 40 + 「聆听中…」16px 灰 + 右侧紫色声浪（5 个 6px 圆点，1.2s 呼吸）；两侧独立白色圆钮（AI 视觉、通话）
- 问屏行（AIOS 2 必备）：聆听条下方或建议行内设「问屏」入口——「识别、总结、比价一句话搞定」：搜同款快捷比价多平台价格、拨打屏中电话、总结屏中内容；原型至少给问屏一个可见入口
- 识屏与拖拽：灵动键/双击电源呼出识屏，圈选后可拖角调大小、拖框移位；二维码识别后小窗打开应用（微信码落微信扫一扫）；拖拽分享带视觉动效；锁屏呼出仅显示时间与通知消息
- 模式选择卡：三张白卡圆角 24 并排（快捷问答 / 自动深度思考 / 全时深度思考）：未激活 = 中性灰字 + 灰 logo；激活 = 原子花 logo 彩色 + 文字 `--ai-text` 渐变
- 动效：面板 320ms 上滑展开（可打断）+ 光晕呼吸；跳转动效轻量，操作等待时长优化后的即时感

## 十八、实况通知（Live Notification，AIOS 核心）

【官方：状态栏胶囊常驻，点击悬浮展开，随时查看进度或操作；覆盖通话、游戏复活倒计时、支付保护、音乐歌词、Aicy 航班火车行程；行程类支持息屏显示；Flyme 12.5 优化 12306 长文本与游戏倒计时消除逻辑】

- 常驻形态：状态栏胶囊小条（应用彩色图标 + 关键状态一句话，如「川航3U8888 · 登机口A12」）；属系统层，普通通知不得占用此形态
- 展开形态：白卡圆角 16，头部同通知卡（应用图标 20 + 应用名 12px + 时间），右侧为实时状态标签 + AI 渐变小标；标题 15px/Medium + 内容行实时刷新；点击通知以悬浮形式展开（非跳应用），悬浮卡支持进度操作
- 息屏：行程类（航班/火车）支持息屏显示关键行；原型涉及行程时给息屏示意行
- 完成态：完成后收敛为常规通知样式；游戏结束不再残留倒计时
- 长文本：12306 检票口类长文本截断 + 展开，不撑破卡片
- 属通知卡片变体，遵循其布局、左滑与点击行为；展开实况卡时通知中心时间日期区让位（真机行为，原型不叠压两者）

## 十九、Aicy 桌面入口胶囊

- 桌面/全局的 Aicy 呼出入口：深灰半透明胶囊 rgba(29,30,34,0.55)（深浅通用）、白色原子花 logo 20 + 「Aicy」白字 15px/Medium、高 44
- 按压 scale(0.96)；仅用于桌面/全局浮层，App 内唤起 Aicy 不复用此样式
