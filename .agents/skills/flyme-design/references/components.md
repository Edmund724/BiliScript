# Flyme 核心组件

每个组件覆盖默认 / 按下 / 禁用 / 加载（适用时）× 浅 / 深主题。通用数值见 design-tokens.md，这里只写组件特有参数。

## 导航与列表

**沉浸式导航**：内容延伸到状态栏下；高 48，标题居中 17 Medium；初始透明，滚动后毛玻璃 + 发丝线。

**分组卡片列表**：组 = 圆角 16 卡片，页面边距 16，组距 12，行高 56。左侧线性彩色图标 24 + 间距 16 + 标题 16（可选副标题 12）；右侧值文字 15 次色 + chevron / 开关。组内默认无分隔线（>6 行用左缩进 72 的发丝线）。按压行底加深，圆角 12。

## 操作件

**按钮**：高 44（大 48 / 小 36），胶囊。主 = 主色底白字；次 = 主色浅底 + 主色字；文字按钮 = 主色字。按压 scale(0.97)；禁用 40%；加载用 spinner 占位保宽。

**输入框**：高 48，圆角 12，filled 底无边框；聚焦 1.5px 主色描边。搜索框为胶囊 + 灰底。

**开关**：51×31 胶囊；关闭 #E3E4E8（深 #3A3B40）；滑块 27 白；250ms。

**滑条**：高 36 胶囊；展示型无把手，可调型 24 白把手。竖向（控制中心）约 76×150、圆角 24，自底部彩色填充。

## 浮层

**弹窗**：原生 `<dialog>` + `showModal`；宽 ≤320，圆角 24；标题 17 Medium 居中；双胶囊按钮横排；入场 scale(0.94→1) + fade；`closedby="any"` + Esc，配 aria。

**底部面板**：顶部圆角 24 + 拖拽条 36×4；上滑 320ms 展开，可打断。

**Toast**：深色胶囊 rgba(29,30,34,0.92)，白字 14；底部上移 120，2s 消失。

**底部操作条**（替代 FAB）：表单 / 详情页底部全宽胶囊主按钮，边距 16 + 安全区避让。

**标签栏**：高 64 + 安全区，毛玻璃；图标 24（选中填充 + 主色），文字 11；切换 250ms fade。

## 控制中心与通知

**控制中心**：全屏毛玻璃；顶部大时钟 + 日期；左列白卡（圆角 20）叠放 WLAN / 数据 / 蓝牙三行，右列亮度 / 音量竖向滑条；媒体卡 + 宽卡行；下方 4 列磁贴（约 72×72，圆角 20，未激活白底灰字，激活功能色填充分白字）。支持自定义与分页，原型至少演示两页 + 编辑态。点按 scale(0.95)，展开 320ms 可打断 + 轻微回弹。

**通知卡**：白卡圆角 16，gap 8；应用图标 20 + 应用名 12 + 标题 15 Medium + 内容 15 次色（2 行截断）。左滑消除。任务型通知改用实况通知。

**实况通知**：状态栏胶囊常驻（一句话状态）→ 点击悬浮白卡展开（实时状态标签 + AI 小标 + 进度操作）→ 完成后收敛为常规通知。行程类给息屏关键行；长文本截断 + 展开。

## Aicy

唯一的系统级大面积彩色界面，流光与呼吸只出现在这里。

**唤醒面板**：`--ai-glow` 光晕底（大圆角 28，4–6s 呼吸）→ 白色建议胶囊行 → 聆听条（白胶囊 64：× 钮 + 「聆听中…」+ 声浪）→ 问屏入口（识别 / 总结 / 比价）→ 三张模式白卡。面板 320ms 上滑，可打断；reduced-motion 下光晕静态。

**管家简报**：淡彩底整组 + 白子卡圆角 16；头部 Aicy logo 24 + 场景标签（`--ai-text`）；简报行 2–4 条（功能色图标 20 + 主文字 15 + 说明 12）。

**桌面入口**：深灰半透明胶囊，高 44，白双环 + 「Aicy」白字；仅桌面 / 全局浮层用。

## 小圆圈

加载 spinner：24 圆环，主色旋转——全系统唯一允许的旋转动效。空状态插画以圆环圆点构图（约 120px SVG）。
