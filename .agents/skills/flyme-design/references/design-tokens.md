# Flyme Design Tokens（现代基准）

基准版本：Flyme 9 / 10 / AIOS / AIOS 2（「轻盈有序」「轻若有灵」；AIOS 2 起 Alive Design——融合秩序与美感、视效动画丝般顺滑）。旧版以 Flyme 5 灰阶极简为底，已废止。

> 出处：魅族未公开组件级设计规范。本文数值分两档——【官方】有官方材料支撑（品牌蓝、毛玻璃通知中心、去线留白、形状语言方向）；【推导】按真机观感与现代移动惯例推导。产出对外一律表述「按 Flyme 设计语言推导」，不得称「官方规范数值」。

## 一、设计哲学

现代 Flyme 三基准：

1. **底色克制、点缀活泼**——大面积中性色打底，色彩集中在功能图标与关键操作。Flyme 8「大胆的色彩」体现在图标与点缀，不在底色。
2. **形状柔和**——操作件胶囊化、容器大圆角（Flyme 8「抹除棱角」；圆角基因源自 mBack 腰圆）。
3. **动效细腻**——「乍一看难以察觉，但细品又如此自然」：克制的缩放/位移/形变，绝不弹跳。

拿不准时选更轻盈的方案：更少装饰、更轻层级、更短更柔的动效。

AIOS / AIOS 2 补充基准：

4. **Alive Design 生命感**——「融合秩序与美感」：普通界面维持克制有序（前三条不变），生命感集中在 AI 场景与壁纸层（Aicy、Alive 壁纸），不向普通列表蔓延。
5. **AI 流光层**——Aicy 唤醒、AI 生成、AI 任务进度使用 AI 专属视觉：流光渐变 + 原子花符号；该渐变禁止移植到普通按钮/卡片。
6. **丝般顺滑**——OneMind 流光视效引擎的 Web 对应：毛玻璃层级克制、动效全程不掉帧、避免长链复合动画。

## 三、形状语言

胶囊只属于操作件；容器大圆角但保持矩形感（禁止把卡片做成胶囊）。

| 组件 | 形状 |
|------|------|
| 主/次按钮、搜索框、滑条 | 胶囊（圆角 = 高度一半） |
| 卡片、列表组 | 圆角 16px（纵览/媒体大卡 20px） |
| 控制中心磁贴 | 圆角 20px |
| 弹窗 | 圆角 24px |
| 底部面板 | 顶部圆角 24px |
| 竖向滑条（控制中心） | 约 76×150、圆角 24 |
| 系统 UI 图标 chip（设置行/控制中心） | 圆形（50%） |
| 桌面图标 | 圆角方形 + 拟物浓彩渐变（仅桌面，App 内不模拟） |
| 输入框 | 圆角 12px |

## 四、间距与密度

4dp 微调网格；间距以 8 的倍数为主。

| 场景 | 数值 |
|------|------|
| 页面水平边距 | 16px |
| 列表组间距 | 12px |
| 组内行高 | 56px（紧凑 48 / 宽松 64） |
| 卡片内边距 | 16–20px |
| 图标容器与文字 | 16px |

旧版「组件间距 ≥16dp、页面边距 24dp」废止：现代 Flyme 密度更高，靠分组卡片组织信息。

## 六、材质与层级

毛玻璃【官方：Flyme 9 通知中心「浅色毛玻璃背景和白色卡片」】：

| 模式 | 配方 |
|------|------|
| 浅色 | rgba(255,255,255,0.72) + backdrop-filter: blur(24px) saturate(180%) |
| 深色 | rgba(16,17,20,0.72) + backdrop-filter: blur(24px) saturate(160%) |

应用于：通知中心、控制中心、滚动后的导航/标签栏、Toast（可选）。回退：不支持 backdrop-filter 时改用 0.95 不透明纯色。

阴影：仅浅色模式浮层用 0 8px 24px rgba(17,18,26,0.10)；深色模式零阴影，用分层灰。

层级：背景 0 → 卡片 1 → 浮层 2 → 弹窗 3 → Toast 4。

## 七、动效

时长 200–350ms；基准缓动 cubic-bezier(0.32, 0.72, 0, 1)，退场 ease-in。

| 场景 | 规格 |
|------|------|
| 按压反馈 | 120ms scale(0.97) |
| 列表/卡片入场 | fade + translateY(12px) + scale(0.98)，逐项 40ms stagger |
| 弹窗 | 250ms scale(0.94→1) + fade |
| 面板（控制/通知中心） | 320ms translateY 下滑展开 |
| 开关/滑块 | 250ms |
| 页面切换 | 300ms fade + 轻视差 |
| 形状连续 | 尺寸/圆角过渡代替硬切（磁贴展开等） |
| AI 流光呼吸（AIOS 2） | 4–6s 环境动效：渐变缓慢位移/旋转，透明度不变；仅 AI 场景 |
| AI 聆听/生成进度 | 声浪圆点约 1.2s 呼吸脉冲——唯一允许的重复脉冲 |

禁区：回弹、过冲、旋转（例外：小圆圈加载 spinner）。

必须实现 prefers-reduced-motion: reduce → 全部退化为 ≤100ms fade；AI 流光呼吸改为静态渐变、声浪点停驻。

## 八、图标

- **功能入口**（设置行/宫格/控制中心）：彩色**圆形 chip**（2.2 色板）+ 白色符号；符号 stroke 2 或填充；关闭/停用态 chip 为中性灰
- **AI 符号（Aicy 原子花，AIOS 2）**：五环原子花——5 个椭圆环 rotate 0/36/72/108/144° 叠加（近似画法），stroke 用 `--ai-logo` 渐变；仅 AI 场景出现
- **导航/标签**：线性 stroke 2，选中态填充 + 主色
- 容器尺寸：40（列表）/ 48（宫格）；线性图标 20/24
- 状态不透明度：默认 100% / 按下 60% / 禁用 30%

## 九、禁忌

1. 大面积高饱和底色（主色仅操作与选中）
2. 直角或 ≤8px 小圆角按钮（操作件必须胶囊）
3. 全灰线性图标列表（功能入口必须彩色容器）
4. 回弹/过冲/旋转动效、超过 400ms 的动效
5. 他系元素：Material FAB/水波纹、iOS 大标题吸顶导航、HarmonyOS 服务卡片
6. 深色模式阴影
7. emoji/色块占位图标
8. AI 流光渐变出现在非 AI 场景（普通按钮/卡片/列表）；普通组件不得引用 `--ai-*` 变量
