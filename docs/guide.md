# 配置与排障指南

在 B 站视频页打开右侧文摘面板，点击右上角齿轮按钮即可打开「设置」抽屉（所有改动即改即存；对话、概览与解释、字幕翻译可各自独立指定模型）。

## 字幕翻译（内置免 Key 开箱即用）

字幕翻译已支持内置免 Key 的 **Bilibili Index-Translate**，无需配置任何 API Key 即可直接在 B 站视频页触发双语字幕翻译；其引擎与模型选择与「总结 / 对话 / 选区讲解」使用的通用 AI 平台完全解耦，不会互相覆盖：

- **默认免费源**：进入「设置 → 字幕翻译与导出」，「翻译来源」默认选中 `Index-Translate（免 Key）`，「翻译模型」默认 `Index-Translate-35B-A3B`，并可直接切换为 `Index-Translate-9B`（均衡）或 `Index-Translate-2B`（轻量）。
- **自定义 AI 平台**：若已配置其他文本模型，也可将「翻译来源」切为 `自定义 AI 平台` 并选用已启用平台中的任意模型。

## AI 模型平台（总结、对话与可选翻译）

1. 进入「设置 → AI 模型平台 → + 添加平台」，选择内置预设或「自定义」。
2. 确认接口协议（**OpenAI 兼容 / Anthropic / Gemini 原生**，切换协议时预设 Base URL 会自动联动）。
3. 粘贴 API Key，点击模型名右侧箭头拉取可用模型（内置目录会自动标注上下文窗口及「思考」「图片」能力徽标），点击「测试」验证通过后自动保存。

- **内置平台预设（14 家）**：DeepSeek、阿里通义千问（Qwen）、智谱 GLM、月之暗面 Kimi、MiniMax、Mimo、Opencode Go、OpenRouter、阶跃星辰（Stepfun）、ModelScope、AMD Radeon Cloud（免费）、SenseNova 商汤（免费）、Ollama（本地）、Google Gemini。
- **免费方案（ModelScope）**：前往 [ModelScope 官网](https://modelscope.cn/) 注册登录，在用户页或 API 管理页创建 `ms-` 开头的 SDK Token（详见 [ModelScope API 文档](https://modelscope.cn/docs/intro/model-service)）。每日签到赠送的免费积分即可满足日常总结与对话。
- **思考强度调节**：点击对话发送框底部的模型胶囊，可通过滑轨切换思考档位（`Default` / `Off` / `Minimal` 至 `Max`），扩展会自动转换为目标平台对应的请求参数。

## 联网搜索（免 Key 开箱即用）

点击对话输入框右侧的地球图标即可开启联网搜索（首次开启会提示数据流向）。回答附带可展开的搜索时间线、来源链接与 `[n]` 内联引用。

| 平台 | 接入形态 | 免费额度 / 计费说明 |
| :--- | :--- | :--- |
| **Tavily（默认链首）** / Firecrawl / AnySearch / Parallel | 内置免 Key | 开箱直连，无须注册账号；Tavily 填入自有 Key 后享每月 1,000 credits |
| 豆包 | 自备 Key | 火山控制台申请 Key，每月 500 次免费额度 |
| Exa | 自备 Key | 每月 10 美元赠送额度（新号另赠 10 美元），7 美元 / 1,000 次 |
| DeepSeek | 复用凭据 | 自动复用 AI 平台中官方 DeepSeek 的 Key；默认在智能链中关闭，需单选或开启「允许智能搜索使用付费平台」 |

**排序与回退机制**：「设置 → 联网搜索」支持拖拽调整优先级，单轮搜索上限默认 5 次（可调 1–20）：
- **智能回退（默认）**：按列表顺序逐家回退，总预算 30 秒；单引擎连续失败 3 次自动进入 5–60 分钟指数退避冷却，5 分钟内相同查询命中本地缓存直接复用。
- **单选平台**：仅请求指定搜索引擎，失败不回退。

## 实时音画伴看（多模态互动）

在「设置 → 实时伴看」添加伴看平台，即可通过播放器控制栏清晰度旁的伴看按钮（或进入 B 站直播间）启动双向语音互动：

- **MOSS Live**：填入 MOSS Live 官方 API Key（默认 Base URL `https://api.mosi.cn`，模型 `moss-live-1.0`）。
- **Gemini Live**：支持 Google Gemini 原生多模态实时协议（如 `gemini-3.8-live`）。若已在「AI 模型平台」配置 Google Gemini，可直接一键复用凭据，并支持开启原生 Google 搜索查证。

## 常见问题（FAQ）

### 为什么有些视频没有字幕？

播放器控制栏无「字幕」选项代表视频无原生字幕轨。配置语音识别平台并开启「无字幕自动语音识别」后会自动抓取音频转写；已有原生字幕的视频不会触发转写或下载音频。

### 模型下拉列表为空或点击「测试」报错怎么办？

依次检查：
1. 首次点击拉取箭头时，是否在浏览器弹窗中授予了该域名访问权限；
2. API Base URL、API Key 与模型名称是否正确且网络可达；
3. 若第三方平台未实现 `/v1/models` 接口，直接在模型框手动输入模型名称即可。

### 支持哪些浏览器？

支持 **Chrome / Edge 120 及以上** 与 **桌面端 Firefox 140 及以上**（不支持移动端 Firefox）。

Firefox 版支持核心文摘阅读、双轨翻译、概览、AI 对话、金句导出、本地 Agent 桥接与无字幕语音转写；语音朗读与实时音画伴看目前仅在 Chromium 浏览器提供。

### 开启代理软件时，语音转写提示「音轨下载或解码失败」怎么办？

B 站音轨 CDN 依赖本地运营商 Local DNS 进行机房调度与防盗链鉴权，代理客户端接管 DNS 易因节点错位被拒连：
1. **推荐解法（无 DNS 泄漏）**：在代理软件的 DNS 设置中，将 **Direct Nameserver（直连 DNS）** 设为 `system`（或路由器 IP `192.168.1.1`），让国内直连流媒体走本地解析；
2. **快捷解法**：开启代理软件的「追加系统 DNS」，或在转写期间临时暂停系统代理。

### ModelScope 提示积分不足或硅基流动转写失败怎么办？

ModelScope 请先前往官网完成当日签到领取免费积分；硅基流动转写失败请查看面板报错提示（已区分 Key 无效、额度不足、防盗链或网络异常），在对应平台补齐额度或切换至上表中的免费模型。

### 联网搜索没生效怎么排查？

1. 确认对话输入框右侧地球图标已点亮，且当前所选对话模型支持工具调用（Function Calling）；
2. 查看提示属于「未配置」还是「全部在冷却中」（后者等待几分钟自动恢复）；
3. 检查搜索模式是否误设为「单选」某一家，切回「智能回退」即可自动按序兜底。
